> **冻结通知（2026-08-12，覆盖下文旧 Setup 生成要求）**：老板已批准并冻结当前 `Assets/Settings/Scenes/M2.unity`。后续程序、Setup 和 Agent 不得修改、创建、重生成或保存覆盖；`M2Setup` 仅为只读打开器。只有老板可在 Unity Scene 中手工修改视觉，后续功能必须走 runtime 动态绑定或已有节点。

## 目标

按审计任务 `08-10-m2-readiness-audit` 的规划产物实现 M2「轨头顶面探测」完整教学流程：全幅主导的主教学场景（A/B/C/D 仅为逻辑分区与对象职责）、耦合剂涂抹、K2.5 探头偏角定位（10°）、沿轨纵向移动探测（150→100mm、110mm 检出）、自制尺测距自动判定、普通/透视切换、紧凑 B 区波形仪器、30/60 秒防卡死帮助、流程重置、右侧常驻全身数字人与问答面板（复用 M1 链路）及可配置下一模块出口。

## 需求（来源于审计产物）

1. 横屏布局：A/B/C/D 仅作为逻辑分区与对象职责，不再表现为四个同权矩形面板；主教学场景全幅化/主导，工具暂存、钢轨、C 模式控件自然融入。1920x1080 设计基准（Scale With Screen Size、Match 0.5），SafeArea 承载业务 UI。
2. 四阶段流程：涂抹耦合剂 → 探头定位与 10° 偏角 → 移动探测（110mm 检出）→ 尺子测距自动判定。
3. B 区为嵌入主场景的紧凑辅助仪器（1920 基准约 460x240，允许 440–480x220–250），低对比、不纵向贯穿、不抢视觉；单条实时波形（平直基线/波峰生长/峰值锁定）由探头位置驱动；110mm 锁定检测结果但允许继续拖过观察峰后下降，不锁死探头、不重复蜂鸣。
4. C 模式控件融入主场景左下，「普通视图 / 透视视图」分段切换，全流程可用，透视自动联动透明钢轨、伤损红转黄、入射/反射声束。
5. D 区弱化卡片感但保持操作提示与步骤控件，固定显示「步骤 x/4 + 阶段名称」；30/60 秒防卡死帮助为 D 区非模态提示，自动演示可平滑完成。
6. 顶部 Header 只保留左侧模块标题与右侧「重置流程」（二次确认，只重置 M2）；无返回 M1、无引导动画。右侧常驻无边框 DigitalHumanStage（约 300–320px 宽，默认全身待机），复用 M1 数字人链路（M1DigitalHumanPresenter / M1PressDetector / VideoPlayer / RenderTexture / UI-LumaKey-DigitalHuman 与待机/思考/讲解视频）；与 M1 一致，面板打开时全身显示且数字人不被 Blocker 压暗或拦截；问答面板在数字人左侧展开；不保留 Header 文字/头像 QAEntry 作为主入口。
7. 自制尺全程可见、前期置灰锁定，测距阶段解锁；0 刻度对齐焊缝熔合线进入容差后自动吸附判定，无「完成测距」按钮。
8. 完成状态收尾：显示「进入下一模块」，出口为 Inspector 可配置 UnityEvent；未配置时保持完成状态显示「下一模块待接入」，不报错、不创建假 M3。
9. 视觉沿用 M1 简洁风格；仅 B 区深色仪器屏且降低对比、紧凑显示。正式素材缺失不阻塞功能原型（占位可替换），但占位效果不作为最终视觉验收。
10. 不复制 M1 QA/数字人逻辑：优先提取 Editor 公共 Ensure 或参数化复用（数字人舞台/问答面板层级）；M1 行为回归必须检查。
