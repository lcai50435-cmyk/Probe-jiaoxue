# M2 功能总收口与视觉坐标校准

## 目标

在已批准的 M2 UGUI 基础上，统一收口剩余功能：让 110mm 检出与透明钢轨上的红色伤损在同一视觉位置发生；增加探头偏角旋转与透视声束反馈；接入完整 QA/数字人链路；修复重置确认暂停、Setup 漂移和 M1→M2 Build Settings；完成 M2 独立与串联 Play Mode 验收。

## 已确认产品决定

- 2026-08-12 起冻结 M2/M3 Scene；2026-08-12 老板为 M2 最终功能收口明确授权一次性定点解冻：只允许接入正式尺子、完整 QA 子树/组件引用和 Build Settings。完成后立即以新哈希重新冻结；`M2Setup` 继续保持只读打开器，M3 始终不修改。
- 玩家看到的红色小区域就是目标伤损。探头到达该区域时必须同时显示 110mm、波形达峰、蜂鸣并锁定检出，禁止视觉位置与判定位置分离。
- 保持 `150→100mm` 连续线性距离合同；通过校准扫描轨迹终点，让红色伤损中心对应 80% 扫描进度，即 110mm。
- 红色伤损继续来自 `Assets/railwayTracks/俯视角透明.png`，不恢复独立 `DamageMarker`，不修改普通视图底图。
- 调整偏角时增加探头旋转表现。由于原始规格描述为“向上偏转 10°”，二维俯视画面中的旋转是教学代理反馈，不解释为真实水平转向；透视声束同步随角度变化。
- 偏角视觉只旋转探头图片子节点，拖拽根节点、命中区域和扫描坐标不旋转，避免交互漂移。
- 正式尺子使用 `Assets/交互动画素材/03 其他素材/多功能尺子.png`；不再使用程序占位条或重复刻度文字。
- 本轮与既有 M2 未实现部分一起收口：完整 QA、正式尺子、重置确认暂停、M1→M2 Build Settings 和最终运行时验收。

## 需求

1. 从透明钢轨素材计算并固化伤损中心对应的 RailViewport 归一化 X；`targetDistance=110mm` 在该 X 触发，手动与自动演示使用同一映射。
2. 保持距离从 150mm 单调线性下降到 100mm；110mm 对应扫描进度 0.8，终点位于伤损右侧，不能用非线性读数伪造对齐。
3. 透视视图中探头中心到达红色伤损 X 时，波形达到 110mm 峰值、蜂鸣一次、显示检出结果；继续越过后波形下降，往返不重复蜂鸣。
4. 角度滑块 `0°→20°` 实时驱动探头图片旋转；10°视觉清晰但克制，根 RectTransform 的锚点、尺寸和拖拽轨迹不变；Reset 恢复 0°。
5. `BeamLine` 与偏角使用同一角度源并跟随探头移动；普通视图隐藏，透视视图显示；手动滑块与自动演示表现一致。
6. M2 完整接入 `M1QAPanel`、`M1DeepSeekClient`、`M1DigitalHumanPresenter`、`M1PressDetector`，QAPanel 从数字人左侧展开，Presenter 的 `qaPanel` 非空。
7. QA 打开时 `Time.timeScale=0`，底层拖拽/动画/帮助计时暂停；关闭恢复打开前值；数字人视频、问答请求、抽屉动画和逐字显示继续使用 unscaled 链路。
8. 重置确认框打开时暂停 `M2IdleHelp` 计时，取消或确认后恢复/重置；不允许确认框停留期间触发自动帮助。
9. 正式尺子替换现有 `Ruler/bg`：保持长宽比、初始可见但置灰锁定，Step 4 解锁；0 刻度对齐焊缝后吸附、显示 110mm，重置/离开时回到初始位置。
10. 完整 QA 从 M1 已验证结构定点复用到 M2 的 QALayer，挂载并注入 `M1QAPanel`、`M1DeepSeekClient` 与 Presenter；不复制 runtime/网络逻辑。
11. `M2Setup` / `M3Setup` 继续只读；本次 Scene 变更只能由一次性 `M2FinalCloseout` Editor 工具执行一次并记录前后哈希，工具不得成为持续生成入口。
12. 完成 M2 独立验收并使用已有幂等 `BuildScenesSetup` 将 M1/M2 设为 Build Settings index 0/1，验证 M1“开始探测”进入 M2。
13. 不新增 M2 runtime 脚本；只扩展既有组件和 Editor-only 收口工具；M2 runtime 每个默认不超过 150 行。
14. 不修改 M1/M3 Scene，不接 M2→M3，不替换数字人素材，不复制 QA 网络逻辑。

## 验收标准

- [ ] 透视模式下探头视觉中心到达红色伤损 X 时当前距离为 `110mm`，波形达峰并只蜂鸣一次；继续移动到 100mm 后波形下降。
- [ ] 手动拖动和自动演示在相同视觉位置产生相同距离、波形和检出结果。
- [ ] 角度滑块实时驱动探头图片与声束；0°、10°、20°状态可辨，10°自动推进；Reset 恢复 0°。
- [ ] 探头图片旋转不改变拖拽根节点、放置容差、扫描轨迹或触控区域。
- [ ] M2 长按数字人可打开完整 QAPanel；抽屉左开、人物不被 Blocker 压暗或拦截，Presenter/DeepSeek/输入/发送/关闭引用完整。
- [ ] QA 打开暂停 M2，关闭恢复；重置确认期间帮助计时暂停；M1 QA 行为无回归。
- [ ] 四阶段流程、30/60 秒帮助、重置后复跑和未配置 M3 完成状态通过 Play Mode。
- [ ] 一次性收口后 M2 重新冻结并记录新 SHA-256；M3 保持 `f5446de3...`，冻结数字人位置 `x=-124, y=-35` 不被覆盖，M1 Scene 无任务外新增变化。
- [ ] Build Settings 中 M1/M2 为 index 0/1；从 M1 进入 M2与直接打开 M2初始状态一致。
- [ ] Unity 编译无 Error，M2 runtime 每个不超过 150 行，`git diff --check` 通过。

- 改变 110mm 教学数值、扫描起止读数或波形阶段定义。
- 本次明确授权范围之外的 M2 视觉改动，以及任何 M3 Scene 改动。
- 修改/重绘钢轨 PNG 或正式尺子 PNG 本体。
- M3 交互、M2→M3 出口和发布构建。
- 外部素材搜索或下载。
