# M2 探头拖拽、字体与波形修复

> **冻结通知（2026-08-12，覆盖下文旧 Setup/Scene 修改要求）**：当前 `Assets/Settings/Scenes/M2.unity` 已由老板批准并冻结。不得通过程序、Setup 或 Agent 修改、创建、重生成或保存覆盖；只有老板可在 Unity Scene 中手工改视觉。后续修复只能走 runtime 动态绑定、已有节点或非视觉组件。

## 目标

修复 M2 当前 Play Mode 中探头暂存位与实际初始位置冲突、探头无法按教学流程拖动、隐藏步骤中文显示方框、文字观感模糊，以及波形无法由手动扫描可靠驱动的问题，使 Step 2~3 的界面表达与实际行为一致。

## 背景与已确认事实

- `ProbeHome` 当前只是空白暂存框；真正的 `Probe` 由 `M2Setup` 直接创建在 `RailViewport` 的扫描起点，导致界面暗示与实际状态冲突（`Assets/Editor/M2Setup.cs:303`、`:383`）。
- `M2ProbeDrag.OnDrag` 首次拖动只执行放置且不跟随指针；角度不是 10° 时后续拖动全部返回，用户观感为“无法拖动”（`Assets/Scripts/M2ProbeDrag.cs:77`）。
- 手动拖动把中心原点的 RectTransform 局部坐标直接除以宽度后当作 0~1 归一化坐标，手动路径无法可靠到达 110mm（`Assets/Scripts/M2ProbeDrag.cs:84`）。
- 隐藏的 `AngleControls` 文本仍引用 `LiberationSans SDF`，进入 Step 2 后中文字形显示为方框；项目已有 `sarasa-gothic-sc-regular_cn` 中文 TMP 字体。
- `M2WaveformGraphic` 已支持程序绘制并由 `NotifyDistance` 驱动，但手动拖动坐标错误阻断完整变化；`growthStartMm`、`peakWindowMaxMm`、`peakWindowMinMm` 尚未参与波形/状态合同。
- 当前 M2 结构必须继续由幂等 `M2Setup` 维护，不直接手改场景 YAML；本修复不新增 runtime 脚本。

## 需求

1. `ProbeHome` 是真实探头初始暂存位：新开 M2 时探头显示在左上 `ProbeHome` 内，不得同时在钢轨上出现第二个探头。
2. Step 1 未完成时探头不可拖动；涂抹耦合剂后进入 Step 2，用户能把探头从暂存位拖到钢轨起始放置区。
3. Step 2 在角度不是 10° 时仍允许完成“暂存位到起始区”的放置；只有沿钢轨纵向扫描受 10° 门控。
4. 探头放置正确且偏角达到 10°时自动进入 Step 3，不要求额外拖动或再次调整滑块。
5. 手动扫描必须按 RailViewport 局部坐标正确映射 `0.143→0.857` 和 `150→100mm`，能到达并跨越 110mm；自动演示与手动使用同一映射合同。
6. 所有 M2 TMP 文本，包括初始隐藏的步骤容器，统一使用项目中文字体；中文不得显示方框。
7. 文字清晰度先消除错误字体和布局采样因素，在 1920x1080、Game View 1x 下无明显异常模糊；不以动态按屏幕宽度缩放字体解决。
8. 波形随手动探头距离连续变化：150mm 基线、125mm 后生长、112~108mm 峰值区、越过 110mm 后下降；110mm 检出仍只触发一次。
9. B 区状态文字至少正确表现“平直基线 / 波峰生长 / 峰值锁定”，检出结果锁定但实时波形允许继续下降；目标距离由标题“目标 110mm”表达，不显示高对比常驻目标竖线。
10. 普通/透视必须切换现有同构素材 `Assets/railwayTracks/俯视角.png` 与 `俯视角透明.png`；伤损位置直接采用透明图内标记，不叠加自制 DamageMarker。底图焊缝只保留不可见测量锚点，不额外绘制深色竖线。
11. 修复只修改 M2 相关 Setup/runtime/场景生成结果，不改 M1 场景和问答历史，不新增专用 runtime 脚本。

## 验收标准

- [ ] 新开 M2 时探头只出现一次，并处于用户确认的初始位置；`ProbeHome` 与真实交互含义一致。
- [ ] Step 1 探头不可拖；涂抹完成后可拖到起始区；0°可放置但不可纵向扫描；调至 10°自动进入 Step 3。
- [ ] Step 3 手动拖动可连续显示 150→100mm，快速跨过 110mm仍检出一次，往返经过不重复蜂鸣。
- [ ] 自动演示与手动拖动在相同视觉位置产生相同距离。
- [ ] Step 2 的“向内偏角”“请增大偏角/偏角正确”等中文无方框；场景内所有 TMP 均引用中文字体或有明确中文 fallback。
- [ ] 1920x1080、1280x720、2436x1125 截图中文字不溢出，1920x1080 1x 下字形边缘清晰。
- [ ] 波形可从基线连续增长至峰值并在越过目标后下降；状态文字与阶段一致，波形区无重复的橙色目标竖线。
- [ ] 普通视图使用 `俯视角.png`，透视视图使用 `俯视角透明.png`；无额外 DamageMarker 或可见 WeldLine 覆盖素材。
- [ ] `M2Setup` 连续运行两次后场景哈希、节点数、组件数不继续变化；重新打开场景后行为仍有效。
- [ ] Unity 6000.3.21f1 编译无 Error；M2 runtime 脚本仍各自不超过 150 行；`git diff --check` 无本次新增问题。

## 已确认产品决定

- 真实探头初始放在左上 `ProbeHome` 内；涂抹耦合剂后由用户拖到钢轨起始放置区，再调整至 10°并进入扫描。
- 透视伤损位置以现有 `俯视角透明.png` 为权威，不再使用程序绘制的独立红色方块；波形目标只保留标题文字，不保留橙色竖线。
