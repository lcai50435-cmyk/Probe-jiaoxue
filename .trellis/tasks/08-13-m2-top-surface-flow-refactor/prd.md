# M2 轨头顶面探测流程重构

## Goal

在不修改冻结 M2 Scene 的前提下，使“定位尺校角、探头保持 10° 前移、绿色检测束命中、110mm 双点复测”形成一致且可验证的教学闭环。玩家应理解 110mm 是探头入射点到红色损伤位置的实际测量距离，而不是探头图像与损伤重合时的抽象扫描读数。

## Background

- 需求依据为 `Assets/交互动画素材/M2轨头顶面探测.pdf`、老板 2026-08-13 口径与 `Assets/交互动画素材/M2待修改部分.pptx`（2026-08-14）；冲突时以最新口径为准。PPT 四点要求：① 探头应卡在定位尺凹槽中；② 校角与测量两个步骤的尺子大小必须相同；③ 测量时尺子应与探头平行（水平放置）、不能盖住探头，测量界面不显示「110mm」字样提示；④ 波形参考「焊筋轮廓波」简化格式，删除「峰值锁定/目标 110mm/平直基线/112mm」等提示词，不加标题。
- 最终测量方向固定为：尺子 0mm 对准探头入射点，尺子 110mm 对准红色损伤位置。PDF 第二页的相反方向不采用。
- 当前实现已有耦合剂、Slider、150→100mm 波形、绿色 `BeamLine`、红色损伤、蜂鸣、尺子、帮助、重置、QA 和完成出口，可复用；其中“检出后继续到 100mm”属于旧实现，不纳入目标玩法。
- `Assets/Settings/Scenes/M2.unity` 已冻结；保护基线 SHA-256 为 `1610da8a14fff92138bfc0554946d7bc909e793c8f05e6126bf8bdd9b61d209a`（= HEAD，老板数字人 X 坐标 `-124 → -13` 调整已随 6dfcae0 提交），实施前后不得变化。

## Requirements

### R1. 流程与门控

- 保留现有四阶段页面骨架：涂抹耦合剂 → 探头定位与校角 → 移动探测 → 尺子复测完成。
- 定位阶段内部依次完成：探头以 0° 放到轨头顶面、Slider 调至 10°、定位尺 10° 槽与探头对位并确认尺身基准线平行钢轨。
- Slider 到 10°本身不能进入扫描；必须同时完成定位尺校角（夹具式合同：尺子 10°槽吸附探头成夹具 → Slider 解锁 → 玩家沿槽调至 10°稳定确认 → 角度锁定 → 玩家拖尺子归回工具架，撤尺后才进入扫描）。校角成功后探头保持向内 10°，Slider 锁定到重置。
- 未涂耦合剂、探头未正确放置、角度不正确或定位尺未确认时，均不能纵向扫描。

### R2. 单一几何距离合同

- 扫描从现有 150mm 起点向损伤方向移动，到 110mm 检出点结束；距离必须由探头入射点到红色损伤点的屏幕几何间距计算，不能继续由归一化拖拽进度伪造。
- 尺子正式素材标定三个配置化锚点：10°槽，以及位于同一可见上沿基线的 0mm 点和 110mm 竖刻线交点；该 `0→110` 二维欧氏像素跨度用于扫描距离换算和最终复测，透明区域或字样位置不得作为测量锚点。
- 150mm 起点和 110mm 检出点均由该比例反算探头位置。110mm 时探头与损伤保持可见间距，禁止探头中心与损伤中心重合；检出后探头立即锁定在该位置，不继续扫描到 100mm。
- 红色损伤点继续从现有 `RailPerspective` 素材坐标换算（`damageUv=(0.4808,0.63)`，2026-08-14 老板反馈后由红椭圆质心 `0.711` 下移至椭圆下部/下缘，视口本地约 `(-24,+93)`，使扫描线/探头下移贴普通视图钢轨踏面；110mm 刻线视觉上仍贴着红椭圆底部）；不新增 `DamageMarker`，不修改图片本体。
- 探头入射点锚定探头发射面（`probeEntryLocal=(0.89,0.04)`，probeFootage 右下楔形，像素验证），使校角时发射面卡入尺子 10°槽、主体在尺子左侧无遮挡，测量时尺子 0mm 端轻触发射面、探头与尺子平行无遮挡，且检测束从发射面视觉位置发出。
- 扫描轨迹线以损伤点 y 为基准：探头入射点与红色损伤点必须位于同一水平线（`scanLineY = damage.y`），保证测量时尺子可水平放置、两锚点同时命中；`startLocal` 不再作为几何距离依据，150mm 起点由损伤点沿扫描方向反算 `damage - 150*ppm`。

### R3. 检测束、波形与反馈

- 探头完成校角后显示并持续发出绿色检测束；普通/透视切换只控制可见层，不改变几何判定或流程状态。
- 检测束起点使用探头入射点，目标方向指向红色损伤；其有效 110mm 长度与尺子 `0→110` 标定跨度一致。
- 仅当探头保持 10°、几何距离进入 110mm 容差且检测束与损伤命中区相交时锁定检出、波形达峰并蜂鸣一次。
- 检出后立即锁定探头和 110mm 峰值，只蜂鸣一次并显示现有“下一步”按钮；玩家点击“下一步”后进入尺子复测，无需继续扫描或返回检出位。
- 波形界面采用简化格式：深色底、浅色网格、橙红波形（平直基线 + 110mm 尖峰锁定），距离刻度 150→110；运行时隐藏 `WaveStateText`/`CurrentDistanceText` 并删除 `waveStateText` 写入逻辑，界面不得出现「峰值锁定/目标 110mm/平直基线/112mm/当前距离」等提示词，波形区不显示标题。

### R4. 尺子双模式

- 同一正式尺子承担两种职责：定位阶段的 10°槽校角，以及检出后的 0/110mm 双点复测；前后阶段不得复制尺子或创建替代 UI。
- 校角模式同时检查 10°槽靠近探头、尺身基准线平行钢轨和 Slider 为 10°；成功后自动吸附确认并归槽。
- 校角与测量两个步骤使用同一工作态尺寸（统一为 `measureSize=420x91`，`angleGuideSize` 保留字段但运行时不再使用），保证前后尺子大小一致、`0→110` ppm 合同不变。
- 测量模式进入时尺子水平放置（`localRotation = 0`，与探头移动方向/钢轨平行），不自动倾斜定向；玩家平移尺子使 0mm 可见点对准探头入射点、110mm 可见刻线对准红色损伤点（两点同线后自然同时命中）；只有两个可见锚点均在容差内才吸附并完成，尺子不得斜放或盖住探头。
- 测量界面不显示「110mm」字样提示：`MeasurementBubble` 中序列化的 `110mm` 文本运行时改为完成反馈文案（不写回 Scene）。
- Reset、完成出口和异常中断均恢复冻结 Scene 中缓存的尺子 Home 初态。

### R5. 防卡死、暂停与重置

- 30 秒定位帮助必须演示完整的“放置探头 → 调至 10° → 定位尺校角 → 归槽”，不能只设置 Slider。
- 60 秒扫描帮助使用与手动操作相同的几何路径移动到 110mm，并触发相同的检测束、波形和蜂鸣判定。
- QA 打开和重置确认期间继续遵守现有暂停合同；帮助、拖拽和动画不得在暂停时推进。
- Reset 必须清除校角、检出、测量和帮助状态，并恢复探头 0°、尺子 Home、150mm 基线和一次蜂鸣锁。

### R6. 实现边界

- 不新增 M2 runtime 脚本；优先重构 `M2FlowController`、`M2ProbeDrag`、`M2RulerDrag`、`M2IdleHelp`，仅在输入合同需要时调整 `M2WaveformGraphic`。
- 新参数使用 Inspector 字段并提供合理默认值，包括尺子锚点、探头入射点、损伤点换算、角度/距离/双点容差和确认时长。
- 运行时脚本默认保持不超过 150 行；现有 `M2FlowController` 与 `M2ProbeDrag` 已达 150 行，新增行为前必须删除旧“进度即距离”和旧单点测量逻辑，不能继续堆叠。
- 不修改或保存 `M2.unity`，不运行任何会写回 M2 的 Setup/Closeout 工具，不修改 M1/M3 Scene、QA 网络链路、素材文件或 Build Settings。
