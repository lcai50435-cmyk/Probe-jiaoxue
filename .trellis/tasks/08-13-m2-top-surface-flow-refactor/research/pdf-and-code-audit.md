# M2 流程重构证据审计

## 1. 用户确认的最高优先级合同

- 保留现有角度 Slider 作为角度输入。
- 定位尺参与 10°校角，不只是装饰。
- 探头校角后保持向内 10°并继续向前移动。
- 探头发出绿色检测束；检测束命中红色损伤时蜂鸣。
- 最终测量方向以用户 2026-08-13 最新决定为准：
  - 尺子 0mm 对准探头入射点；
  - 尺子 110mm 对准红色损伤位置。

该测量方向覆盖 PDF 第二页中相反的“0 对焊缝、110 对探头”标注。

## 2. PDF 证据

来源：`Assets/交互动画素材/M2轨头顶面探测.pdf`，2 页。

PDF 流程：

1. 涂抹耦合剂。
2. 探头以 0°正放在轨头顶面。
3. 用定位尺将探头向内偏转 10°；定位尺水平线与钢轨边缘平齐。
4. 撤掉定位尺，探头保持 10°向前移动。
5. 探头入射点与焊缝/损伤位置相距约 110mm 时出波。
6. 再次使用定位尺确认出波位置。

与用户口径一致的部分：0°初放、尺子校角、向内 10°、撤尺后前移、110mm 出波、再次测量。

冲突部分：PDF 第二页把 0mm 放在焊缝、110mm 放在探头；用户明确要求反向，故实现必须以用户最新决定为准。

## 3. 正式尺标定与空间预算

来源：`Assets/交互动画素材/03 其他素材/多功能尺子.png` 与冻结 Scene 序列化尺寸。

### 素材锚点

- Sprite 原始尺寸：`2102x455`，RGBA。
- 0mm 锚点：尺身左端可见上沿，Unity 底左原点 UV `(0.000000, 0.950000)`；旧 `(0,0.5)` 落在透明区域，不能用于视觉测量。
- 110mm 锚点：蓝色 110mm 竖刻线与同一可见上沿的交点，Unity 底左原点 UV `(0.726927, 0.950000)`；禁止取字样下方或刻线中部。
- 10°槽锚点：右侧 10°凹槽尖角，素材像素约 `(1612, 171)`，左上原点 UV `(0.766889, 0.375824)`；Unity 底左原点 UV 约 `(0.766889, 0.624176)`。
- 锚点是实施默认值，最终由 Play Mode 双点误差与人工视觉复核确认；实现不得改 Sprite。

### 1920 基准空间预算

- Scene：`MainScene` 宽 `1920-48=1872px`；`RailArea` 再扣除右侧 `592px`，宽 `1280px`；`RailViewport` 左右各 16px，最终宽约 `1248px`。
- 尺子工作态：`measureSize=420x91`；素材宽高比 `2102/455=4.62`，与 Rect 比例一致，实际显示宽约 `420px`。
- 0→110 两锚点位于同一可见上沿，二维欧氏跨度即 `420 * 1528 / 2102 = 305.31px`，故 `pixelsPerMm≈2.7755`。旧 `307.05px` 斜距来自不同高度锚点，是不可见标定错误。
- 对应欧氏间距：150mm 起点=`416.33px`、110mm 检出点=`305.31px`。
- 红色损伤中心按现有 RailPerspective 换算后约为 RailViewport 本地 `x=-39.37px`；最终 150/110mm 探头入射点由该欧氏比例和配置化扫描方向在运行时反算，不沿用旧水平投影估值。
- RailViewport 水平范围为 `[-624, 624]px`；最左 150mm 点加探头半宽 60px 后仍距边界约 108px。当前冻结布局可容纳完整扫描，不需要修改 Scene。

## 4. 当前代码合同

### `M2FlowController`

- 当前状态：`Couplant → Positioning → Scanning → Measuring → Completed`。
- 当前检出条件：扫描读数从 150mm 跨越 110mm。
- 当前步骤文案包含“向前移动探头（150→100mm）”和“0 刻度对齐焊缝熔合线”。
- 已有蜂鸣、DetectionBanner、MeasurementBubble、重置、QA暂停和完成出口。

### `M2ProbeDrag`

- 已分离 `probeRt` 拖拽根与 `probeVisual=Probe/bg` 旋转视觉。
- 已有 Slider 角度输入、10°门控、扫描轨迹和 `BeamLine`。
- 当前距离由扫描轨迹线性映射为 150→100mm，并把探头中心到达伤损中心定义成 110mm。
- 该旧合同与最新“0mm 对探头入射点、110mm 对损伤”的可见间距冲突：探头与损伤不能在 110mm 时重合。重构必须用正式尺 0→110 锚点跨度换算几何距离。

### `M2RulerDrag`

- 当前只有一种测量模式：尺子实际图像左缘作为零点，对齐 `WeldLine` 即完成。
- 已有 Home/工作态切换、Scene 初态缓存、preserveAspect 实际渲染边缘计算和自动吸附。
- 新流程需要改成两种模式：10°校角和 0/110 双点测量。

### `M2WaveformGraphic`

- 当前由连续 150→100mm 输入驱动基线、生长、110mm 峰值、峰后下降。
- 可保留波形绘制组件，但距离来源必须改为探头入射点到损伤点的几何距离；新玩法在 110mm 命中后锁峰，不进入旧的峰后下降区间。

### `M2IdleHelp` / `M2RuntimeSmoke`

- 帮助当前会自动设置 10°、自动滑到 110mm。
- 烟测当前断言 150→100mm、110mm 为 80%扫描进度、尺子零点吸附焊缝；后半段需按新合同重写。

## 5. 冻结 Scene 能力与缺口

M2 Scene 已冻结，现有可复用节点：

- `AngleSlider`
- `Probe/Probe.bg`
- `Ruler/Ruler.bg`、`ProbeHome`、`RulerHome`
- `RailPerspective`（红色损伤烘在透明钢轨图中）
- `BeamLayer/BeamLine`
- `WeldLine`
- `DetectionBanner`
- `MeasurementBubble`（已有 110mm 文案）
- 波形区及 `CurrentDistanceText`、`TargetDistanceText`、100/150 刻度

缺口与限制：

- 没有独立 `DamageMarker`，普通视图不能单独显示红色损伤，命中点需从 `RailPerspective` 素材坐标换算。
- `BeamLine` 只有一条绿色 Image，可实现长度展开和亮度脉冲，但不能直接表达复杂粒子路径。
- Scene 序列化文案仍含 150→100mm、当前 150mm 和波形 100/150 刻度。冻结规则禁止写回视觉；Flow 在运行时改写操作提示，扫描到 110mm 即结束，100mm 刻度不作为可到达玩法终点。
- Scene 中旧测量提示“0 刻度对齐焊缝熔合线”会被 Flow 在运行时按新合同更新；不得保存回 Scene。
- 工作区中的 M2 Scene 已有用户未提交的位置调整；实施不得覆盖。

## 6. 低代码结论

- 不新增 M2 runtime 脚本。
- 修改既有 `M2FlowController`、`M2ProbeDrag`、`M2RulerDrag`、`M2WaveformGraphic`、`M2IdleHelp`。
- 复用现有绿色 BeamLine、蜂鸣 AudioClip、正式多功能尺、DetectionBanner 和 MeasurementBubble。
- 角度、坐标锚点、容差、动画时长全部使用 Inspector 字段，不硬编码到流程判断。
- 视觉节点缺口不由 runtime 动态伪造；冻结 Scene 的必要视觉改动单独过授权门槛。
