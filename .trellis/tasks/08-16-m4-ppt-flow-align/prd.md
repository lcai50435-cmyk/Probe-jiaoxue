# M4 轨腰探测流程按 PPT 对齐并复用 M2 射线/波形

## Goal

按 `文档/M4轨腰部位探测.pptx` 为流程基准，实现 M4 轨腰部位探测模块。几何目标继续使用老板确认的“红色损伤中心”，波形、射线、伤损反馈、尺子素材复用 M2 已验收能力，伤损波联动按 PPT 的 55→45→40 规则。

## 已确认产品口径

- 40mm 目标 = 红色损伤中心，不是焊缝熔合线。
- 扫描起点 = PPT 的“钢轨左侧、轨腰左上端、无偏角”。
- 角度 = 定位尺水平放置，探头向上偏转 10°。
- 波形 = 复用 M2 波形窗口与 M2WaveformFx 样式；伤损波联动按 M4 PPT：
  - >55mm：无伤损波
  - 55mm：短波出现
  - 55→45mm：逐渐变高并左移
  - 45→40mm：保持最高并左移
  - 40mm：检出锁定
- 射线反馈 = 复用 M2：正常绿色，检出后橙色。
- 伤损反馈 = 检出后红色损伤也要变为橙色。
- 尺子 = 复用 M2 的 `尺子正面.png`，同一把尺承担 10° 校角与 0/40mm 复测。
- 钢轨素材 = 使用 `Assets/railwayTracks_2/正视角.png` 与 `正视角透明.png`。
- 探头素材 = 使用 `Assets/probeFootage/probeFootage.png`（M2 已用的 probeFootage）。
- 耦合剂 = 进入 M4 自动展示约 2s 已涂薄膜，不新增涂抹按钮。
- 完成出口 = “轨腰部位探测完成”，通过 Inspector UnityEvent 接下一模块；未配置时显示“下一模块待接入”。

## Requirements

### R1. 流程骨架

```text
Intro(2s 耦合剂已涂)
→ Positioning(0° 放置 + 定位尺 10° 校角 + 撤尺)
→ Scanning(沿轨腰最上端前移至 40mm 检出)
→ Measuring(尺子 0mm 对探头入射点、40mm 对红色损伤中心)
→ Completed
```

### R2. 几何合同

- 红色损伤中心是唯一几何目标：
  - 扫描距离
  - 检测束命中
  - 40mm 检出
  - 尺子 40mm 锚点
  均以该点为准。
- 扫描线沿轨腰最上端，起点为轨腰左上端视觉位置。
- 尺子 `0→40mm` 锚点标定必须来自 `尺子正面.png` 的可见刻度基线；`pixelsPerMm = distance(0mm, 40mm) / 40`。
- 探头入射点锚定探头发射面，检测束从入射点发出。

### R3. 波形

- 复用 `M2WaveformFx`，不复制脚本。
- M4 参数：
  - `scanMinMm = 0`
  - `scanMaxMm = 200`
  - `appearMm = 55`
  - `peakMm = 45`
  - `stopMm = 40`
  - 初始/Reset 距离 = `scanStartMm`
- 波形窗口使用 M2 的 4:3 深色仪器屏风格：点状网格、横轴 0~200mm、纵轴 0~100、常驻绿色始波、底部绿色噪声基线、伤损波与始波同形同色。
- 检出后波形锁定在 40mm 状态。

### R4. 射线与伤损反馈

- 扫描阶段显示绿色检测束。
- 检出瞬间：
  - 射线由绿色变为橙色（复用 M2 的 `beamDetectedColor` / 渐变 Sprite）
  - 红色损伤变为橙色
  - 蜂鸣一次
  - 探头锁定
- Reset 后射线恢复绿色、伤损恢复红色。

### R5. 尺子

- 同一把 M2 尺子承担：
  - 定位阶段：10° 槽校角
  - 测量阶段：0mm 对探头入射点，40mm 对红色损伤中心
- 校角与测量使用相同工作态尺寸（复用 M2 合同）。
- 测量时尺子水平放置，不允许自动斜放。

### R6. 防卡死与暂停

- 30 秒定位帮助：自动演示放置探头、10° 校角、撤尺。
- 60 秒扫描帮助：自动沿几何路径移动到 40mm 并触发相同检出。
- QA/Modal 暂停时波形、帮助、拖拽不推进。
- Reset 清除校角、检出、测量、波形、射线/伤损颜色，恢复起点。

### R7. 素材合同

- 钢轨普通视图：`Assets/railwayTracks_2/正视角.png`。
- 钢轨透视视图：`Assets/railwayTracks_2/正视角透明.png`。
- 探头：`Assets/probeFootage/probeFootage.png`。
- 尺子：`Assets/Resources/尺子正面.png` 或 M2 同款 `尺子正面.png`。
- 波形：M2 4:3 仪器屏风格。

### R8. 复用与修改边界

- 优先复用 M2 组件：`M2FlowController`、`M2ProbeDrag`、`M2RulerDrag`、`M2WaveformFx`、`M2CouplantFx`、`M2IdleHelp`。
- 修改 M2 脚本时必须以默认值保持 M2 现有行为不变。
- 不得修改冻结的 `M2.unity` / `M3.unity`；M4 使用新建 `M4.unity`。

## Acceptance Criteria

- [ ] AC1：M4 从 2s 耦合剂自动展示进入定位，无涂抹按钮。
- [ ] AC2：探头 0° 放到轨腰左上端后，尺子 10° 槽校角成功，角度锁定并撤尺进入扫描。
- [ ] AC3：扫描距离由红色损伤中心与探头入射点几何距离计算；40mm 检出时射线变橙、伤损变橙、蜂鸣一次、探头锁定。
- [ ] AC4：波形复用 M2 样式；伤损波 55mm 出现、45mm 最高、保持最高到 40mm 锁定；Reset 恢复初始状态。
- [ ] AC5：尺子 0mm 对探头入射点、40mm 对红色损伤中心，双点同时满足才完成；单点不通过。
- [ ] AC6：30s/60s 帮助自动演示与手动走同一几何路径并触发相同反馈。
- [ ] AC7：M2/M3 冻结 Scene SHA-256 不变；M2 现有烟测继续通过。
- [ ] AC8：M4 新增 `M4Setup.cs`、`M4Shot.cs`、`M4RuntimeSmoke.cs`，覆盖三视口、Play Mode 流程和波形/射线/伤损/尺子断言。
- [ ] AC9：M4 未配置 M5 出口时稳定显示“下一模块待接入”，不报错。
