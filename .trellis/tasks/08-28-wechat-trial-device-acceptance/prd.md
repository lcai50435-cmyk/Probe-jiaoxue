# 微信体验版与跨平台验收

## Goal

在安全、包体和数字人修复子任务全部通过后，完成可重复构建、Android及微信双端真机回归，并交付仅体验成员可访问的体验版二维码和证据。

## Dependencies

必须先完成并归档：

- `08-28-wechat-ai-security-boundary`
- `08-28-wechat-package-slimming`
- `08-28-wechat-digital-human-polish`

任何P0未通过时不得上传体验版。CloudBase代理未就绪时可上传“QA禁用”范围的体验构建，但不得把问答列为已验收；父任务要求完整问答时仍保持阻塞。

## Requirements

1. 使用干净、可追踪的Unity 6000.3.21f1构建日志重新生成微信和Android产物。
2. 核对主包<4MB、`wasmcode`存在、`webgl.data<=40MB`、无客户端密钥和致命构建异常。
3. Android APK回归M1-M5、引导视频、常驻数字人、长按问答和所有拖拽。
4. 微信Android和iPhone各至少一台执行冷启动、缓存启动、左右横屏及M1-M5全流程。
5. 重点留证：引导颜色、字幕间距、引导结束数字人、三态切换、QA、M2-M5数字人和内存/异常日志。
6. 先上传带版本号的CDN数据，再上传同版本小游戏代码；不得覆盖旧CDN版本目录。
7. 微信后台只设置体验版，不提审、不发布；记录版本号、说明、二维码时间、体验成员和回滚版本。

## Acceptance Criteria

- [ ] Unity/微信/Android构建均成功，日志无C#、Shader、TMP或资源致命错误。
- [ ] 主包、wasmcode、data和安全扫描全部满足前三个子任务门槛。
- [ ] Android、微信Android、微信iPhone完整通过M1-M5及交互清单。
- [ ] 引导颜色/字幕/数字人三项原始真机问题均有修复前后截图。
- [ ] M2/M3 Scene SHA256不变。
- [ ] 后台体验版已设置，二维码仅受邀有效成员可进入。
- [ ] 至少两个受邀账号扫码成功；版本、CDN、二维码、测试和回滚信息已归档。
- [ ] 未执行正式提审、备案或公开发布。

## Out Of Scope

- 正式版提审、备案和公开上线。
- 绕过微信体验成员权限。
- 在本任务内继续开发前三个子任务未完成的功能。
