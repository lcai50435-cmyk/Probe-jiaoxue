# M1 界面横屏适配与视觉优化 — 技术设计

## 1. 架构与边界

不改运行时代码（`M1QAPanel.cs`、`M1ToolSelection.cs` 零改动）。全部改动落在：

- **`Assets/Editor/M1QASetup.cs`**：常量与 `CreatePanel()` 布局参数（保证未来新建面板/重跑 Setup 一致）。
- **场景 `Assets/Settings/Scenes/M1.unity`**：已有对象的序列化数据，通过**新建幂等 Editor 工具 `Assets/Editor/M1LayoutPolish.cs`**（菜单 `Tools/M1/优化 M1 界面布局`）统一迁移，替代手工改 YAML。
  - 理由：改动点 20+ 处（坐标/尺寸/组件属性/父物体迁移），工具可重复执行、可验证，符合项目 M1Setup/M1QASetup 的"Editor 工具代替手工搭建"惯例，符合低代码倾向。
- 场景层级事实（已查证）：
  - `画板`(Canvas+CanvasScaler) > `标题栏`(全宽灰条 160px) > `标题`("请选择钢轨探伤工具")
  - `画板` > `白板背景`(全屏) > `物品`(2×3 卡片容器) > 6 张卡片
  - `画板` > `QAPanel` > Panel > Header / MessageList / InputRow（由 M1QASetup 生成）

## 2. 目标布局参数（1920×1080 参考空间）

| 项 | 现值 | 目标值 | 需求 |

布局计算依据：
- 面板左边界 = 1920-700 = 1220；卡片右边界 = 1220-26 = 1194；容器宽 1164 → 左边界 30，`pos.x = 30+582 = 612`。
- **容器 anchor 必须从 (0.5,0.5) 改为 (0,0.5)**：match=0 后 18:9/20:9 参考空间横向富余（2160/2400 宽），若保持中心锚定，容器会随参考空间中心右移并与右侧面板重叠；左锚定后卡片区恒从屏幕左侧 30 起，面板固定右侧，中间空隙随屏幕加宽自动增大。
- 垂直：标题栏 [960,1080]（高120）；容器中心 y=600（pos.y=60），容器 [216,984]，与"点击继续"按钮（底部 anchor，[80,156]）不重叠。
- 输入行三元素 420+12+110+12+110 = 664 = 700-18×2（面板内边距 18）✓。

## 3. 数据流与契约

- `M1QASetup.cs` 常量同步新值：`PanelWidth=700`、`HeaderHeight=100`、`InputRowHeight=120`，`CreatePanel()` 内输入框 420、语音 110/30、发送 110/30、标题 40、计数器挂到 InputField/Text Area 右下角。保证**新建面板与迁移后的旧面板一致**。
- `M1LayoutPolish.cs`（幂等）：按名称查找场景已有对象并设置目标值；重复执行结果不变（不创建对象、不重复迁移父物体）。
- `M1QAPanel.cs` 零改动：消息气泡 `BubbleMaxWidth=560` < 面板内容宽 700-28 ✓；语音/发送按钮按路径解析，尺寸变化无影响 ✓。

## 4. 兼容性与迁移

- 计数器父物体迁移（InputRow → InputField/Text Area）：`SetParent` 后重设 local 属性；`M1QAPanel.cs` 按路径 `QAPanel/Panel/InputRow/CounterText` 查找——**路径变了，需同步改为 `QAPanel/Panel/InputRow/InputField/Text Area/CounterText`**，并在 Setup 的 `counterTextPath` 字段更新。
- 场景内其他引用（`M1Setup.cs` 的 `EnsureSprites`、`M1ToolSelection` 路径）不受影响。
- 重复执行 M1Setup/M1QASetup 的幂等性校验保持不变。

## 5. 权衡与风险

- **发送按钮 130→110**：用户反馈"语音和发送大小不一致" → 等宽 110×78 最直接；发送作为主按钮观感变化，若用户不满意可单独回退发送宽度。
- **锚点语义变化**（物品容器 0.5→0）：宽屏行为改变是本次核心目的，16:9 下位置与现观感接近（左边界 30 vs 10.6，右边界 1194 vs 1121），需在编辑器多比例验证。
- **无法本环境验证**：Unity 场景改动必须由用户在编辑器打开验证（验收清单见 implement.md）。
- **回滚**：改动集中在 git 可跟踪的文件（`M1QASetup.cs`、新 `M1LayoutPolish.cs`、场景），`git checkout` 可整体回滚；工具幂等，可重复运行。
