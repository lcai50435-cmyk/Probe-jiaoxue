# PRD: M1 开场引导动画

## 背景

游戏（M1 场景）进入后直接开始，缺少引导环节。需要开场播放一段引导动画（3D 卡通角色 + 旁白音轨，约 15 秒），让玩家先了解操作背景再开始。

## 需求

1. **进入时机**：M1 场景正常加载后，立即进入引导状态。
2. **暂停**：引导期间游戏处于时间静止（`Time.timeScale = 0`），游戏 UI 不可交互。
3. **遮罩**：半黑透明遮罩（黑度 0.75~0.85）压暗游戏画面，遮罩期间后方 UI 完全不可交互。
4. **视频**：播放 `引导动画-1（有音轨版）.webm`（30fps、1080×1450 竖屏、约 15 秒、含音轨）。
   - 播放策略：方案 A——按高度适配居中，两侧留黑（遮罩区域），不变形不裁切。
   - 视频黑底与高黑度遮罩视觉融合，无需透明通道。
5. **结束**：视频播放完毕（`loopPointReached`）→ 恢复 `timeScale = 1`、隐藏遮罩、正式开始游戏。
6. **首次记忆**：用 `PlayerPrefs` 记录"首次进入"标记。
   - 首次进入：自动播放，**不能跳过**。
   - 非首次进入：自动播放但可**点击跳过**（点击遮罩/视频区域即跳过）。——（注：此处行为待用户最终确认，先按"仍自动播放 + 可跳过"实现，配置开关可切换为"非首次直接不播"）
7. **跳过开关**：配置项 `allowSkip`（Inspector 字段）控制是否允许跳过；首次进入强制 `false`。

## 约束

- 低代码优先：运行时逻辑必须写代码（首次检测/暂停/恢复），搭建走 Editor 工具（`M1Setup.cs`），保持幂等。
- 新增 runtime 脚本 ≤150 行，命名 `M1IntroVideo`（如超限拆分）。
- 不硬编码：视频引用、遮罩黑度、UI 路径、PlayerPrefs key 均走 Inspector/常量配置。
- webm 在目标机实测播放；若解码失败，同路径 mp4 版本无缝替换（代码不变，仅换引用）。

## 验收标准

1. 首次进入 M1：游戏暂停、半黑遮罩、竖屏视频居中播放（含声音）、UI 不可点。
2. 视频播完：自动恢复游戏，遮罩消失，无报错。
3. 第二次进入：仍自动播放，点击可跳过；跳过/播完均恢复正常游戏。
4. 删 PlayerPrefs 后再次进入恢复首次行为。
5. `M1Setup.cs` 重复执行幂等，不产生重复引导对象。

## 最终实现（2026-08-08 完成）

- 方案变更：用户看效果后改为**黑底抠像 + 人物悬空**（非黑底融合），新增 `UI-LumaKey.shader` 抠像
- 非首次行为确认：仍自动播放、可点击跳过（已按此实现）
- 视频开头卡顿：`Prepare()` 预解码 + `prepareCompleted` 后再播放
