# M2 实现与素材就绪度审计

审计日期：2026-08-10

## 审计范围

- `文档/仿真交互动画技术规格书.docx`
- `文档/功能文档.docx`
- `Assets/` 内现有场景、脚本、图片、视频、音频及 Unity `.meta`
- `ProjectSettings/EditorBuildSettings.asset`

本次只核对本地库存，不搜索或下载外部素材。

## 结论

1. **M2 可以立即开始实现，但只能按“功能骨架 + 可替换占位素材”开工。** 四区布局、流程状态、耦合剂动画、拖拽/角度校验、110mm 位置映射、三态波形、蜂鸣、防卡死均不依赖新增美术素材。
2. **素材不齐全，当前不具备 M2 最终视觉验收条件。** 缺少可直接使用的干净钢轨俯视底图、透明钢轨透视底图、透明背景自制尺成品。
3. **完整 M1 -> M2 流程尚不能验收。** M1-2 探头选择已实现，但“开始探测”尚未切换到 M2；Build Settings 仍指向 SampleScene。
4. **波形实现口径已在规划中确认。** 采用程序绘制单条实时波形，由探头位置驱动平直基线、波峰生长、110mm 峰值锁定和峰后下降；3 个参考 MP4 只用于确认形态，不等待序列帧素材。

## M2 需求基线

依据技术规格书 3.2 与功能文档第二、三章：

| 步骤 | 需求基线 | 参数/反馈 |
|---|---|---|
| 初始 | A/B/C/D 四区分屏；探头锁定 | B 区无波形，提示涂耦合剂 |
| Step 1 | 点击涂耦合剂 | 2 秒浅蓝半透明扩散后消失；按钮置灰 |
| Step 2 | 放置探头和自制尺，滑块调整偏角 | 向内 10°；角度错误禁止前移 |
| Step 3 | 探头沿钢轨纵向前移 | 150-100mm 映射波形；112-108mm 达峰；110mm 为目标点并蜂鸣 |
| Step 4 | 拖尺测距 | 0 刻度对齐熔合线；读数 110mm；放大气泡；尺子归位 |
| 透视 | 可贯穿所有步骤开关 | 透明钢轨、伤损红转黄、绿色入射/反射线；按降级方案不做流动粒子 |
| 防卡死 | 30 秒角度帮助、60 秒移动帮助 | 自动演示 10° 定位或滑行到 110mm |

## 已发现冲突与歧义

### 1. M2 参考图距离错误

技术规格书正文、联动表、测量步骤和结束参数表均要求目标距离 **110mm**；但 `轨头顶面探测.png` 的右侧标注为 **100mm**。实现应以文档多处重复的 110mm 为准，该图片不能直接带标注使用。

### 2. 波形实现方式内部冲突

`功能文档.docx`：

- 第三章降级表写“程序绘制三态关键波形（平线/生长/峰值）”。
- 第四章又写“不做程序化实时波形绘制，以高密度序列帧替代”。
- 第五章素材清单再次写“程序 Canvas 绘制”，且本地没有高密度序列帧。

规划已确认采用“程序绘制单条实时波形 + 探头位置驱动平滑过渡”，因为它与降级验收表、现有素材库存和低代码要求一致；不采用高密度序列帧。

### 3. 完整流程前置不满足

- `Assets/Scripts/M1ToolSelection.cs` 已实现 M1-2 探头选择，但“开始探测”仍明确记录“M2 轨顶面探测尚未实现（占位）”。
- `Assets/Settings/Scenes/M2.unity` 已存在，但仅有空 Canvas/EventSystem，且 CanvasScaler 仍为 Constant Pixel Size；尚无 M2 Setup。
- `ProjectSettings/EditorBuildSettings.asset` 仍只启用 `Assets/Scenes/SampleScene.unity`。
- 按两份文档，M1-1 正确项应为“超声波焊缝探伤仪”；当前代码默认值为“手推式钢轨探伤仪”。这是现实现与文档基线冲突，需在全流程联调前确认。

这些问题不阻止独立开发 M2，但阻止按文档验收 M1 -> M2 端到端流程。

## 建议开工边界

### 可立即开始

- 基于现有 M2 占位场景新增幂等 M2 Setup 和场景骨架，并把 CanvasScaler 统一为 1920x1080、Scale With Screen Size、Match 0.5。
- 四区响应式横屏布局。
- 配置化步骤状态与 150-100mm 位置映射。
- 耦合剂 2 秒 UI 动画。
- 探头/尺子拖拽、10°滑块校验、110mm 测量。
- 三态波形、蜂鸣、提示气泡、30/60 秒帮助流程。
- 透视开关逻辑和临时线段/伤损占位。

### 最终视觉验收前必须补齐

1. 干净的轨头顶面钢轨/焊缝俯视底图，不带探头、箭头、距离文字。
2. 与普通底图同构图的透明钢轨透视底图，或可分层的钢轨/伤损素材。
3. 抠好透明背景、透视校正后的自制尺 PNG；刻度需能清楚表达 110mm。

## 文档原始布局还原

技术规格书 3.2.1 的 Word 矢量布局图实际表达如下；图中右侧单独画出的 D 区矩形是 **D 区内部结构的放大说明**，不是屏幕上的第五块区域。

```text
┌──────────────────────────────────────────────────────────┐
│                  M2 轨头顶面探测                         │
├───────────────────────────────┬──────────────────────────┤
│ A 区：探测区                  │ B 区：波形显示区         │
│ 钢轨俯视图、焊缝、探头、      │ 距离刻度、始波、杂波、   │
│ 自制尺、耦合剂和透视效果      │ 动态峰值                 │
│                               │                          │
├───────────────────────────────┤                          │
│ C 区：透视开关                │                          │
├───────────────────────────────┴──────────────────────────┤
│ D 区：提示文字 | 当前核心按钮 | 偏角滑块/数值/状态       │
└──────────────────────────────────────────────────────────┘
```

相对关系：

- A/B 构成主工作区，A 约占主工作区 60%，B 约占 40%。
- C 是 A 下方的窄工具条，只负责普通/透视状态切换；B 在右侧向下延伸。
- D 是底部横跨全宽的操作栏，内部上层显示当前步骤提示，下层放当前主按钮与偏角状态。
- D 的核心按钮随步骤替换：`涂抹耦合剂` -> 角度/移动状态 -> `下一步` -> 测距完成/进入 M3。

## 补充参考图评估

用户提供的两张“钢轨探伤3-定点”手机截图可作为交互概念参考，但不满足 M2 成品需求：

- 已体现：探头位置变化、透视开关、缺陷标记、波形/示意显示区域。
- 未体现：涂抹耦合剂、拖拽操作、10°偏角滑块与强制校验、自制尺测量、110mm 距离显示、蜂鸣与下一步、30/60 秒防卡死。
- 透视效果只显示黑色圆点和简单线条，没有文档要求的透明钢轨、轨头下颚伤损、绿色入射/反射路径、伤损红转黄和高亮闪烁。
- 波形只凭截图无法证明与位置动态联动，也未显示文档要求的“杂波 -> 波峰生长 -> 最高点 -> 下降消失”。
- 页面为竖屏浏览器截图且存在大面积空白，与“手机横屏优先”的四区布局不符。
- 两个文件均为 1264x2780 RGB 截图，无透明通道，浏览器状态栏、标题栏和菜单已烘焙进图片，不能直接作为 Unity 分层素材。

结论：**可借鉴“普通/透视两态 + 波形区”的概念，不可直接作为 M2 场景素材或验收依据。**

## 最终判定

- **现在是否可以开始实现 M2：可以。** 建议按功能优先、素材可替换的方式开工。
- **素材是否齐全：不齐全。** 核心逻辑素材基本够用，最终视觉素材至少缺 3 项；全流程还受 M1/M2 场景串联和 Build Settings 影响。
