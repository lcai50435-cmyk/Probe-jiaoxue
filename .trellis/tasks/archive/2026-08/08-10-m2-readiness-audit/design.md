# M2 UGUI 与交互规划

> 状态：规划草案，待用户审核。本文不授权或触发场景、运行时代码和素材实现。

## 1. 目标与边界

### 1.1 目标

在横屏手机优先的前提下，实现 M2“轨头顶面探测”的完整教学流程：

1. 涂抹耦合剂。
2. 放置 K2.5 探头并调整向内偏角至 10°。
3. 沿钢轨纵向移动探头，联动距离与单条实时波形，在 110mm 检出伤损。
4. 使用自制尺对齐熔合线并自动判定 110mm 测距结果。
5. 右侧常驻全身数字人（复用 M1 数字人链路）提供问答入口，问答面板在数字人左侧展开。
6. 支持普通/透视切换、防卡死帮助、流程重置和可配置下一模块出口。

### 1.2 实施边界

- 允许先使用可替换占位素材完成逻辑和布局验收。
- 不播放 M2 引导动画（数字人仅作为常驻问答载体，非入场引导）。
- 不提供返回 M1。
- 不实现 M3 交互，仅提供可配置下一模块出口。
- 不复制 M1 QA/数字人逻辑：Editor 侧优先提取参数化公共 Ensure（数字人舞台/问答面板层级），M2Setup 复用；M1 行为回归必须检查。
- 不把用户提供的参考截图直接作为场景素材。
- 最终视觉验收仍需干净钢轨俯视底图、同构图透明钢轨底图和透明背景自制尺成品。

## 2. 已确认设计决策

- A/B/C/D 保留为逻辑分区与对象职责，不再表现为四个同权矩形面板：主教学场景全幅化/主导，工具暂存、钢轨、C 模式控件自然融入。
- B 区为嵌入主场景的紧凑辅助仪器（1920 基准约 460x240，允许 440–480x220–250），低对比、不纵向贯穿、不抢视觉。
- 视觉沿用 M1 的简洁风格，不使用复杂渐变、强发光和玻璃拟态。
- B 区只显示一条实时波形；状态为“平直基线 / 波峰生长 / 峰值锁定”。
- 距离、目标线和波形状态集中在 B 区，D 区不重复距离。
- C 区“普通视图 / 透视视图”分段切换，控件融入主场景左下。
- D 区弱化卡片感但保留步骤/控件，使用“步骤 x/4 + 阶段名称”，不做四节点进度条。
- 110mm 锁定检测结果而非锁死探头，允许继续拖动观察峰后下降。
- 尺子始终可见，但仅在测距阶段解锁；对齐后自动判定，不设置“完成测距”按钮。
- 保留带二次确认的“重置流程”。
- 防卡死帮助使用 D 区非模态提示。
- 右侧常驻全身数字人（无边框 DigitalHumanStage 约 300–320px 宽）：复用 M1 数字人链路（M1DigitalHumanPresenter / M1PressDetector / VideoPlayer / RenderTexture / UI-LumaKey-DigitalHuman 与待机/思考/讲解视频），默认全身待机；问答面板在数字人左侧展开；与 M1 一致，面板打开时全身显示、数字人不被 Blocker 压暗或拦截；不保留 Header 文字/头像 QAEntry 作为主入口；不播放 M2 引导动画。
- M2 以“完成状态 + 可配置下一模块出口”收尾。

## 3. 画布与响应式基线

### 3.1 Canvas

- `CanvasScaler.uiScaleMode`：`Scale With Screen Size`
- `referenceResolution`：`1920 x 1080`
- `screenMatchMode`：`Match Width Or Height`
- `matchWidthOrHeight`：`0.5`
- 根节点使用 `SafeArea`，所有业务 UI 位于安全区内。
- 当前 M2 占位场景的 `Constant Pixel Size / 800x600` 需要由 Setup 幂等修正。

### 3.2 参考尺寸

以下尺寸是 1920x1080 设计基准，由 Setup 管理，不进入运行时代码：

| 区域 | 建议尺寸/比例 |
|---|---|
| 页面外边距 | 24px |
| 区域间距 | 16px |
| Header | 80px 高 |
| D 区 | 约 176px 高（弱化卡片感，保留步骤/控件） |
| B 区（紧凑辅助仪器） | 约 460x240（允许 440–480x220–250），嵌入主场景，不纵向贯穿 |

- 1920x1080

- 耦合剂、伤损和声束不得烘焙进钢轨底图。

- 重置确认是唯一必要的居中模态框。

## 6. 四阶段交互流程

### 6.1 Step 1：涂抹耦合剂

初始状态：

- 探头显示在 `ProbeHome`，但不能拖动。
- 尺子显示在 `RulerHome`，降低透明度并锁定。
- B 区显示“平直基线”，波形为低幅杂波或平线。
- D 区提示“请先涂抹耦合剂”。

点击“涂抹耦合剂”后：

1. 按钮进入不可重复点击状态。
2. 浅蓝半透明覆盖层从焊缝中心向左右扩散，时长 2 秒。
3. 覆盖层淡出，但流程状态保留“已涂抹”。
4. 按钮显示“已涂抹”并置灰。
5. 探头解锁，流程进入 Step 2。

耦合剂只覆盖钢轨顶面，不覆盖整个 A 区；不需要瓶、刷子或手动涂抹素材。

### 6.2 Step 2：探头定位与偏角

- 用户把探头从暂存位拖到钢轨起始放置区域。
- 偏角滑块范围 `0°–20°`，初始 `0°`，整度步进。
- 小于 10°：提示“请继续增大偏角”。
- 大于 10°：提示“偏角过大，请调小”。
- 等于 10°：状态变绿，提示“偏角正确，可以向前移动探头”。
- 位置正确且角度为 10° 后自动进入 Step 3，不增加“确认角度”按钮。
- 偏角不正确时允许调整起始放置位置，但禁止沿钢轨纵向前进。

### 6.3 Step 3：移动探测

- 探头沿预设纵向轨迹移动，UI 位置映射为 `150mm → 100mm`。
- 角度偏离 10° 时暂停纵向移动；调回后继续，不重置探头位置。
- B 区实时显示当前距离、状态和一条动态波形。
- 到达 110mm 时：
  - 触发一次蜂鸣；
  - 锁定检测成功状态；
  - 显示“峰值锁定”；
  - 高亮 110mm 目标线；
  - 保留峰值标记；
  - 显示“下一步”。
- 不锁死探头。用户继续拖过 110mm 时，实时波形进入下降段；检出结果和“下一步”保持，不重复蜂鸣。
- 点击“下一步”进入 Step 4。

### 6.4 Step 4：尺子测距

- 尺子恢复正常透明度并短暂高亮，允许从暂存位拖出。
- 用户将 `0` 刻度对齐本侧焊缝熔合线。
- 进入可配置容差后自动吸附并判定完成。
- 显示 `110mm` 放大气泡，播放正确反馈，尺子短暂锁定。
- 不设置“完成测距”按钮。
- 尺子和读数保持可见，直到用户点击“进入下一模块”。
- 点击后尺子归位，M2 进入完成状态并调用可配置出口。

## 7. 波形与距离契约

### 7.1 单条实时波形

B 区不并列展示三张状态图。波形由探头位置驱动，参考视频只用于确认形态。

建议将关键距离作为 Inspector 参数：

| 参数 | 默认值 | 表现 |
|---|---:|---|
| scanStart | 150mm | 平直基线/低幅杂波 |
| growthStart | 可调，建议 125mm | 波峰开始生长 |
| peakWindowMax | 112mm | 进入峰值区间 |
| target | 110mm | 峰值锁定、蜂鸣、检出成功 |
| peakWindowMin | 108mm | 离开峰值区间 |
| scanEnd | 100mm | 波峰下降并趋于消失 |

目标检测不能依赖浮点值“恰好等于 110”；应通过前后帧跨越目标或进入可配置目标容差来判定，且只触发一次。

### 7.2 B 区显示

- 左上：`平直基线 / 波峰生长 / 峰值锁定`
- 右上：当前距离
- 次级信息：目标 `110mm`
- 主图：单条实时波形
- 底部：`150–100mm` 刻度
- 110mm：固定目标竖线；检出后变为强调色

检测成功后，标题保持“峰值锁定”，但主波形仍可随探头继续移动显示下降过程。

## 8. 普通与透视模式

C 模式控件融入主场景左下，使用固定尺寸的两段式控件：

```text
显示模式  [ 普通视图 | 透视视图 ]
```

- 初始为普通视图。
- 全流程可切换，不改变步骤、探头位置、角度、波形和测量结果。
- 透视模式显示透明钢轨、伤损点、绿色入射/反射线。
- 伤损初始为红色，检出后转黄并短暂高亮。
- 不实现流动粒子。
- 不设置独立“缺陷标记”按钮。
- 检出后若用户尚未使用透视，短暂高亮 C 区并显示“试试透视视图”，不弹窗。

占位阶段使用同构图 UGUI 钢轨轮廓：普通状态为不透明，透视状态降低透明度；伤损和声束继续保持独立层。

## 9. 防卡死帮助

### 9.1 偏角阶段 30 秒

- D 区提示“需要帮助调整到 10° 吗？”
- 提供“自动演示”和“继续尝试”。
- 自动演示在约 1 秒内平滑将滑块调整至 10°。
- 继续尝试关闭提示并重新计时。

### 9.2 移动阶段 60 秒

- D 区提示“即将演示目标点探测”。
- 短暂停留后锁定冲突输入，探头从当前位置自动滑向 110mm。
- B 区同步展示增长和峰值锁定，按正常流程蜂鸣并显示“下一步”。
- 演示结束后恢复手动输入。

任何有效拖拽或滑块操作都会重置当前阶段计时；打开 QA 抽屉、重置确认框或应用暂停时暂停计时。

## 10. Header、重置与问答

### 10.1 Header

- 左侧只显示“M2 轨头顶面探测”，不放返回 M1 按钮。
- 右侧只保留“重置流程”（二次确认），不再保留文字/头像 QAEntry 作为主入口。
- 不播放进入引导动画。

### 10.2 重置流程

点击“重置流程”弹出二次确认。确认后重置：

- 耦合剂状态与覆盖动画；
- 探头位置、偏角与拖拽状态；
- 尺子位置、透明度、锁定和测距结果；
- 当前步骤与帮助计时；
- 波形、当前距离、目标标记与检出结果；
- 普通/透视状态恢复普通视图。

不返回 M1，不重播引导，不修改问答历史；数字人舞台与问答状态不随流程重置。

### 10.3 问答入口与数字人

- 右侧常驻无边框 `DigitalHumanStage`（约 300–320px 宽），默认全身待机；复用 M1 数字人链路：`M1DigitalHumanPresenter`、`M1PressDetector`、`VideoPlayer`、`RenderTexture`、`UI-LumaKey-DigitalHuman` 材质与待机/思考/讲解视频。
- 与 M1 一致：长按数字人打开问答面板；面板打开时全身显示，数字人节点位于 Blocker/QAPanel 之上，不被压暗或拦截。
- `QAPanel` 在数字人左侧展开（布局参数与 M1 右侧抽屉区分）；复用现有 `M1QAPanel` 与 `M1DeepSeekClient` 运行时能力，保留用户 API 配置。
- 不保留 Header 文字/头像 QAEntry 作为主入口。
- 不复制 M1 QA/数字人逻辑：Editor 侧提取参数化公共 Ensure（根节点、面板宽度、面板展开方向、是否含数字人舞台），M2Setup 通过公共 helper 生成；修改公共 helper 前检查 `M1QASetup` 与 M1 场景用户改动，并运行 M1 QA 幂等回归。
- 问答抽屉打开时全局暂停游戏（`Time.timeScale=0`，关闭时恢复打开前值）：Blocker 锁定底层操作，M2 计时/拖拽/动画一并静止；数字人视频（VideoPlayer）与面板滑入动画不受 timeScale 影响照常运行。由公共组件 `M1QAPanel` 统一实现（`pauseGameOnOpen` 可配置，默认开）。

## 11. 视觉与素材策略

### 11.1 风格

- 沿用 M1 中文字体、按钮、面板边框和简单配色。
- A/C/D 使用浅色或中性背景。
- B 区使用深色仪器屏幕，但降低对比、紧凑显示（约 460x240），不抢主场景视觉。
- 正常/完成：绿色；引导/选中：M1 主色；目标峰值：黄色；阻止/错误：红色。
- 不使用整页紫蓝渐变、持续强发光和大量半透明卡片。

### 11.2 素材使用

可直接使用：

- `Assets/probeFootage/探头素材（无白边版）/K2.5.PNG`
- `Assets/Audio/E-03 蜂鸣报警音/蜂鸣报警音.mp3`
- `Assets/Audio/E-05 拖拽_点击音效/`
- 轨头顶面参考视频只用于波形形态参考

数字人（复用 M1，无需新素材）：

- 待机/思考/讲解三个 MP4（`Assets/DigitalHuman/A-01 待机动画/`、`A-02讲解动画/`、`A-03 思考动画/`）
- `Assets/Shaders/UI-LumaKey-DigitalHuman.mat`（常驻数字人专用 LumaKey 材质，收窄 KeySmooth；RT 开 mipmap，`frameReady` 显式 `GenerateMips`）
- `M1DigitalHumanPresenter` / `M1PressDetector` 组件直接复用，M2 不新增数字人 runtime 脚本

使用占位：

- 钢轨俯视底图：UGUI 简化钢轨与焊缝，不使用带探头/文字的合成截图。
- 透明钢轨：与普通占位钢轨同构图，改变透明度。
- 自制尺：简化尺身和必要刻度，明确标出 0、100、110、150mm。
- 数字人静态审核阶段：先预留舞台/构图，使用可识别的全身预览或 Play Mode 运行截图；正式视频/Presenter/QA 在核心流程后接入。

最终替换要求：

- 钢轨普通/透视素材必须同尺寸、同构图、同焊缝坐标。
- 钢轨图不得包含探头、声束、伤损、文字和交互标记。
- 自制尺需要透明背景、透视校正和可读刻度。
- 用户提供的侧面钢轨图只作为造型与声束路径参考，不直接进入 M2 普通视图。

### 12.1 Editor Setup

### 12.2 必要运行时组件

只为配置无法表达的行为新增薄组件，默认每个脚本不超过 150 行：

| 组件 | 单一职责 |
|---|---|
| `M2FlowController` | 状态迁移、计时、重置、成功标志、UI 状态协调和下一模块出口 |

数字人/问答复用 M1 组件（`M1DigitalHumanPresenter`、`M1PressDetector`、`M1QAPanel`、`M1DeepSeekClient`），不为 M2 新增数字人 runtime 脚本。

不为耦合剂、透视按钮、普通按钮分别新增脚本；由 FlowController 统一协调现有 UGUI 组件。若实现时单一控制器超过行数或职责失焦，再按交互边界拆分，不提前增加抽象。

### 12.3 配置化字段

- 全部用户文案；

- 测距吸附容差；

- 下一场景名称或 `UnityEvent` 出口。

## 13. 组件数据流

```text
Slider / ProbeDrag / RulerDrag / Buttons
                    │
                    ▼
             M2FlowController
      ┌─────────────┼─────────────┐
      ▼             ▼             ▼
 A区场景状态   B区WaveformGraphic  C/D区状态与提示
      │             │             │
      └────── 检出/测距完成 ──────┘
                    │
                    ▼
       Completion UnityEvent / nextScene
```

契约：

- FlowController 是步骤和成功状态的唯一所有者。
- ProbeDrag 只报告位置/距离，不直接修改波形文字或下一步按钮。
- WaveformGraphic 只消费距离和显示参数，不判断流程完成。
- RulerDrag 只报告对齐成功，不直接切换模块。
- Reset 统一由 FlowController 调用各组件显式复位接口，避免节点自行猜测状态。

## 14. 完成状态与下一模块出口

测距成功后：

1. 显示“轨头顶面探测完成”。
2. D 区显示“进入下一模块”。
3. 当前 M2 独立验收以完成状态出现为终点。
4. 若配置下一场景，则调用场景出口；未配置时保持完成状态并显示“下一模块待接入”，不报错、不创建假 M3。

出口优先使用 Inspector 可配置的 `UnityEvent`；确需按场景名跳转时再配置场景名并校验 Build Settings。

## 16. 风险与回滚

- 占位钢轨与正式素材构图不一致会导致交互坐标重做，因此正式普通/透视图必须同构图；所有锚点以 RailViewport 本地归一化坐标保存。
- 现有 QA Setup 与全身数字人耦合：M2 复用同一链路（Presenter/PressDetector/材质/视频），必须通过参数化公共 Ensure 提取，禁止复制整段实现；修改公共 helper 前检查 `M1QASetup` 与 M1 场景用户改动，并做 M1 回归；回归失败则回滚公共提取，M2 保留无数字人的降级入口（如临时隐藏舞台），不影响主流程。
- M2 场景当前仅为空 Canvas，所有结构由 Setup 生成；回滚时可删除 M2Setup 生成的命名节点并恢复占位场景，不影响 M1。
- Build Settings 和 M1“开始探测”跳转属于端到端串联，需在 M2 独立流程通过后再接入。
