# M2 实现与素材就绪度审计

## 目标

依据 `文档/仿真交互动画技术规格书.docx` 与 `文档/功能文档.docx`，核对 M2 的功能边界、交互流程、实现前置条件和本地素材库存，判断 M2 是否可以开始实现，以及素材是否齐全。

## 要求

1. 完整提取两份 DOCX 中所有与 M2 相关的需求，不以文件名或目录名代替正文核对。
2. 盘点项目内与 M2 相关的场景、脚本、图片、视频、音频、模型及其 Unity `.meta` 文件。
3. 建立“需求/步骤 -> 所需素材或技术能力 -> 当前证据 -> 状态”的对应关系。
4. 将状态区分为：可直接实现、可用占位或现有素材先实现、阻塞实现、文档存在歧义。
5. 给出明确结论、缺失素材清单、非素材阻塞项和建议的开工范围。
6. 本任务只做本地审计，不修改运行时代码、场景或素材，不搜索和下载外部素材。
7. 基于需求文档和用户提供的横屏参考图，给出可落地的 M2 UGUI 区域比例、层级结构和必要调整，不把参考图直接作为场景素材。
8. B 区为嵌入主场景的紧凑辅助仪器（1920 基准约 460x240，允许 440–480x220–250），降低对比、不纵向贯穿、不抢视觉；仍只显示一条与探头位置实时联动的波形；顶部状态文字依次显示“平直基线”“波峰生长”“峰值锁定”，探头到达 110mm 时锁定并高亮，不同时并列三张状态波形。
9. M2 视觉风格沿用 M1 的简洁风格与现有字体、按钮和面板语言，不引入复杂渐变、强发光或玻璃拟态；仅 B 区使用深色仪器屏幕以增强波形辨识度。
10. 测距阶段不设置“完成测距”按钮；自制尺 `0` 刻度进入焊缝熔合线容差范围后自动吸附并判定完成，显示 `110mm` 放大气泡和正确反馈，再显示“下一步”。
11. 探头到达 110mm 时锁定检测结果而非锁死探头：触发一次蜂鸣、保留 110mm 峰值标记并显示“下一步”；用户仍可继续拖过目标点查看峰后下降，离开目标点不撤销成功状态、不重复蜂鸣。
12. A/B/C/D 保留为逻辑分区与对象职责，不再表现为四个同权矩形面板：主教学场景全幅化/主导，工具暂存、钢轨、C 模式控件自然融入；第二张参考图仅用于“工具在上、钢轨居中、探头沿轨移动”关系，不采用其纵向页面结构。耦合剂作为钢轨顶面的浅蓝半透明覆盖层，从焊缝中心向两侧扩散 2 秒后淡出；完成前锁定探头，完成后解锁。
13. 自制尺从进入 M2 起始终显示在 A 区工具暂存位，但前期置灰并锁定；检出 110mm、进入测距阶段后高亮并解锁。对齐成功后保留尺子和 110mm 读数供观察，点击“下一步”进入后续模块时再归位。
14. 偏角滑块范围为 `0°–20°`，初始值 `0°`，使用整度步进，必须精确到向内 `10°` 才允许探头沿钢轨纵向移动。偏离目标时保留探头位置但暂停纵向移动，调回 10° 后继续；D 区实时显示当前角度和过小、过大、正确状态。
15. 顶部右侧保留简洁的“重置流程”按钮并提供二次确认；确认后只重置 M2：耦合剂、探头、尺子、偏角、波形、检出结果、测距结果和帮助计时全部恢复初始状态，不返回 M1、不重播引导。
16. M2 测距成功后以“完成状态 + 可配置下一模块出口”收尾；当前独立验收到完成状态为止，不制作假 M3 功能。下一场景或后续动作通过 Inspector 配置，M3 就绪后无需修改 M2 核心交互即可接入。
17. 进入 M2 后直接显示四区操作界面，不播放“引导动画-2”，现有 M1IntroVideo 复用不纳入本次 M2 范围。
18. M2 右侧常驻显示全身数字人：无边框 DigitalHumanStage（约 300–320px 宽），复用 M1 数字人链路（M1DigitalHumanPresenter / M1PressDetector / VideoPlayer / RenderTexture / UI-LumaKey-DigitalHuman 及待机/思考/讲解视频）；与 M1 一致，面板打开时全身显示且数字人不被 Blocker 压暗或拦截；问答面板在数字人左侧展开；不保留 Header 文字/头像 QAEntry 作为主入口。
19. M2 不提供返回 M1 的按钮；顶部左侧只显示模块标题，模块内重新操作统一使用“重置流程”。
20. 防卡死帮助复用 D 区且不弹居中模态框：偏角阶段 30 秒无操作时提供“自动演示/继续尝试”，自动演示平滑设置到 10°；移动阶段 60 秒无操作时提示后自动滑行到 110mm，并同步波形和蜂鸣。所有有效操作重置当前计时，自动演示期间暂时锁定冲突输入。
21. B 区顶部集中显示波形状态、当前距离和 110mm 目标，图中保留目标竖线和 150–100mm 距离刻度；命中后高亮当前距离和目标线。D 区不重复距离信息，只显示操作提示、当前步骤控件和进度。
22. D 区弱化卡片感但保持步骤与控件，右侧固定显示简洁的“步骤 x/4 + 阶段名称”，四阶段依次为涂抹耦合剂、探头定位、移动探测、尺子测距；不制作四节点进度条。帮助提示只替换 D 区左侧和中间内容，不改变右侧进度。
23. C 区使用“普通视图 / 透视视图”分段切换，初始为普通视图，全流程可用且不改变当前步骤。透视状态自动控制透明钢轨、伤损和声束，不设置独立“缺陷标记”按钮；检出后若用户尚未体验透视，只短暂高亮 C 区提示。
