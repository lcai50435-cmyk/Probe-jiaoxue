# M3 实现与素材就绪度审计

## 目标

分析现有技术文档、Unity 工程能力与本地素材，判断是否足够在独立 `M3.unity` Scene 中实现“轨头侧面探测”，并形成可执行的 UGUI、交互、复用与验收基线。本任务仅做审计和规划，不实现 M3，不搜索或下载外部素材。

## 已确认事实

1. M3 是第二方位“轨头侧面探测”：K2.5 探头置于轨头侧面，向下偏转 13°，从右侧向焊缝移动，在距本侧焊缝熔合线约 120mm 处检出轨头下颚伤损。
2. M3 主流程为：进入时展示已涂耦合剂状态 -> 探头与多功能尺定位 13° -> 150mm 至 100mm 移动探测 -> 120mm 检出 -> 多功能尺测距确认 -> 进入 M4。
3. 波形区间为：150-140mm 基线/杂波、140-125mm 波峰生长、124-118mm 峰值区、118-100mm 峰后下降；目标点不能依赖浮点精确等于 120mm。
4. 现有 `Assets/railwayTracks/正视角.png` 与 `正视角透明.png` 为同尺寸 2292x740 RGBA Sprite，可作为 M3 普通/透视同构底图；当前目录未纳入 Git。
5. K2.5 透明探头、蜂鸣/正确/错误/拖拽/点击音效、中文 TMP 字体、轨头侧面波形参考视频、数字人三态视频和 QA 组件均存在。
6. 现有自制尺只有 3024x4032 JPG 实拍，含蓝色桌面背景和透视畸变；可证明 13°/120mm 尺型，不能作为最终透明拖拽物。
7. 仓库尚无 `M3.unity`、M3 Setup 或 M3 runtime 组件；Build Settings 仍只启用 SampleScene。
8. M2 已具备流程控制、探头拖拽、尺子拖拽、程序波形、30/60 秒帮助、透视和数字人/QA 的近似能力，但类名、状态机首阶段、文字和部分坐标仍绑定 M2，不能复制后只改数字。

## 需求

1. M3 使用独立 `Assets/Settings/Scenes/M3.unity`，结构由幂等 `Assets/Editor/M3Setup.cs` 生成；M3 Setup 不打开或保存 M1/M2。
2. Canvas 使用 `Scale With Screen Size`、1920x1080、Match 0.5，业务 UI 位于 SafeArea；目标视口为 1920x1080、1280x720、2436x1125 横屏。
3. 视觉延续 M2：主教学场景全幅主导，A/B/C/D 只作为逻辑职责，不做四个同权矩形面板；B 区为约 460x240 的紧凑辅助仪器；C 模式控件融入左下；D 区为底部操作带；右侧保留 300-320px 无边框全身数字人舞台。
4. M3 默认不要求用户重复涂抹耦合剂。进入场景时播放约 2 秒浅蓝薄膜提示并直接进入定位阶段；从 M2 串联和直接打开 M3 的初始状态应一致。
5. 定位必须同时满足探头位于轨头侧面起始区、定位尺到位、向下 13°；角度或工具位置错误时允许调整但禁止沿扫描轴前进。
6. 扫描距离从 150mm 连续映射到 100mm；120mm 首次命中时蜂鸣一次并锁定成功结果，但不锁死探头，允许继续观察峰后下降。
7. 检出后进入测距阶段，尺子 0 刻度进入焊缝熔合线容差后自动吸附并显示 120mm；不增加“完成测距”按钮。
8. 普通/透视全流程可切换且不改变状态；透视显示半透明钢轨、独立伤损标记和入射/反射声束，按功能文档降级为线段，不做流动粒子。
9. 30 秒定位帮助和 60 秒扫描帮助为 D 区非模态提示；有效操作重置计时；QA 打开、重置确认或应用暂停时暂停 M3。
10. 复用 M1 数字人/QA 链路，QAPanel 打开时 `Time.timeScale=0`，关闭恢复打开前值；不复制网络、视频或问答逻辑。
11. 完成出口使用 Inspector 可配置 UnityEvent；M4 未配置时稳定显示“下一模块待接入”，不创建假 M4。
12. 正式视觉验收前需补齐透明背景、多功能尺透视校正成品；伤损与声束保持独立可替换层。
