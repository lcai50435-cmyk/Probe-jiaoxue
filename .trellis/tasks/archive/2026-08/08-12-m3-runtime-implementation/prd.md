# M3 轨头侧面探测玩法流程重构

## Goal

在不由程序修改冻结 M3 Scene 的前提下，将现有“位置/进度触发”流程重构为可验证的教学闭环：自动展示耦合剂状态 -> 探头 0°放置 -> Slider 与正式尺完成向下 13°校角 -> 探头从 150mm 起点移动 -> 绿色检测束命中内部损伤并在 120mm 锁定 -> 点击下一步 -> 正式尺完成入射点到本侧焊缝熔合线的 0/120mm 双点复测。

玩家应理解：120mm 是探头入射点到本侧焊缝熔合线交点的表面测量距离；绿色检测束命中的是钢轨内部损伤，两者是独立目标、共同构成检出条件。

## Background

- 需求依据为 `Assets/交互动画素材/M3轨头侧面探测.docx` 与老板 2026-08-13 的逐项确认；冲突时以后者为准。
- DOCX 明确要求：探头先正放，使用定位尺向下校到 13°，撤尺后保持 13°前移，出波后以尺子 0mm 对探头入射点、120mm 对本侧焊缝熔合线。
- 当前实现已有 Intro、Slider、探头/尺拖拽、150->100mm 读数、`IncidentBeam`、`ReflectedBeam`、`DamageMarker`、蜂鸣、波形、帮助、Reset、QA 和完成出口，可在原组件内重构。
- 当前旧实现仍以 60%拖拽进度代表 120mm，以单点尺位代表校角和测量，并在检出后自动进入 Measuring；这些旧合同全部废止。
- M3 Scene 是冻结视觉权威。当前审计 SHA-256 为 `e07dcaf60894ae628fd40be0ccc5eeafcfb2e88d226d07cb5e7aafc4507c6aaf`；老板补齐前置视觉后必须记录新哈希并重新冻结。

## Requirements

### R1. Intro 与顺序门控

- 进入 M3 时自动展示约 2 秒耦合剂薄膜，不要求玩家重复涂抹；Intro 不占 3 个业务步骤。
- Intro 使用 scaled 计时，QA 或应用暂停时不得推进。
- Intro 结束后只解锁探头；Slider 和尺子保持锁定。
- 玩家必须先将探头以 0°放到轨头侧面的 150mm 几何起始位，成功后才解锁 Slider 与定位尺。
- 直接打开 M3、从 M2 进入和 Reset 后复跑的初态必须一致。

### R2. 13°尺子校角

- 保留现有 Slider 作为角度输入，不实现尺子带动探头旋转。
- 同一把正式多功能尺承担校角和最终复测，不复制尺子。
- 定位模式由系统预设尺子方向，玩家只负责拖动；不新增旋转控件。
- 校角必须同时满足：Slider 为向下 13°、正式尺 13°槽靠近探头校角锚点、尺身基准线与轨头侧面上边缘平行。
- 任一单条件不得进入扫描。三项通过后尺子自动确认并归槽，Slider 锁定到 Reset，探头保持向下 13°。
- 校角完成前不显示正式检测束；完成后立即显示绿色检测束并进入 Scanning。

### R3. 150->120mm 几何扫描

- 扫描从探头入射点距本侧焊缝熔合线交点 150mm 的位置开始，向熔合线移动。
- 实时距离必须由 RailViewport 本地像素中的“探头入射点 -> 熔合线交点”欧氏距离换算，不能由归一化拖拽进度伪造。
- 正式尺 `0mm -> 120mm` 的二维渲染跨度是唯一毫米比例；不得只取水平投影。
- 100mm 只保留为冻结波形的旧视觉刻度，不是可到达玩法终点。
- 120mm 有效命中后探头立即锁定在首次命中位，不允许继续移动或往返触发。

### R4. 绿色检测束与检出

- 复用现有 `IncidentBeam`，只做单条绿色 UGUI 线段；不增加粒子、动画贴图或复杂材质。
- 检测束从探头入射点沿探头当前向下 13°方向发射，使用配置化有效长度，不自动追踪或转向损伤。
- 普通与透视视图都持续显示绿色检测束；视图切换不得改变射线几何、命中判定或流程状态。
- 现有黄色 `ReflectedBeam` 在运行时始终隐藏，不参与流程或判定。
- 有效检出必须同时满足：Flow 处于 Scanning、探头保持 13°、表面距离进入 120mm 容差、绿色线段与内部损伤命中区相交。
- 有效检出后波形锁定 120mm 峰值，蜂鸣一次，探头锁定，并显示“下一步”；后续操作不得重复蜂鸣。
- 表面 120mm 目标与内部损伤命中目标必须分开计算，最终尺子不测内部声束长度。

### R5. 视图与命中反馈

- 普通视图在命中前不提前显示内部损伤。
- 有效命中后在熔合线附近持续显示黄色 `DamageMarker` 作为命中落点；测量和完成态保留，Reset 或离开模块时清除。
- 透视视图保留内部损伤关系；普通/透视共用同一个命中事实。
- 测量和完成期间继续保留锁定探头、绿色检测束、黄色命中标记和 120mm 峰值。

### R6. 下一步门控

- 与当前 M2 合同一致，M3 使用扫描阶段专用 `NextButton`。
- `NextButton` 文案为“下一步”，初始隐藏，仅在 120mm 有效命中后显示；样式、尺寸和 D 区摆放参考 M2。
- 点击一次后按钮立即隐藏并进入 Measuring；点击前尺子不得进入测量模式。
- 现有 Completed 阶段的 `EnterNextButton` 继续只承担模块出口，不得混用。

### R7. 0/120mm 双点复测

- 最终测量起点是探头入射点；终点是“从入射点出发的测量方向”与本侧焊缝熔合线的交点，不固定取 `WeldLine` 节点中心。
- 进入 Measuring 时，系统将正式尺本地 `0mm -> 120mm` 锚点向量自动对齐“入射点 -> 熔合线交点”目标向量；玩家只负责拖动尺子。
- 只有 0mm 锚点对准探头入射点且 120mm 锚点对准熔合线交点时才自动吸附；任一单点对准不得完成。
- 双点成功后播放一次正确音效，显示现有 `MeasurementBubble` 的 120mm 结果并进入 Completed；不新增旋转控件或“完成测量”按钮。
- 完成态尺子保持吸附并显示；Reset、异常中断或进入下一模块时才恢复冻结 Scene 中缓存的 Home 初态。

### R8. 帮助、暂停与重置

- 30 秒定位帮助完整演示“0°放置 -> 解锁 Slider/尺子 -> Slider 13° -> 13°槽对位/尺身平行 -> 尺子归槽 -> 进入扫描”，并使用与手动操作相同的几何判定。
- 60 秒扫描帮助使用与手动相同的几何路径移动到 120mm，触发真实射线命中、蜂鸣、锁定和“下一步”显示后停止，不自动点击下一步。
- 帮助不得直接写 Flow 成功状态；有效操作重置 idle 计时。
- QA 打开、重置确认和应用暂停期间，Intro、帮助、拖拽、稳定计时和自动演示都不得推进。
- Reset 确认后重新播放 Intro，并恢复探头 0°/Home、尺子 Home、Slider 0°且锁定、150mm 基线、普通视图；清除校角、射线、标记、检出、测量、蜂鸣锁和帮助状态，但不清空 QA 历史。

### R9. 实现边界

- 不新增 M3 runtime 脚本；重构现有 `M3FlowController`、`M3ProbeDrag`、`M3RulerDrag`、`M3IdleHelp`，按需更新 `M3RuntimeSmoke`。
- 复用 `M2WaveformGraphic`、M1 QA/数字人链路、现有音效和现有 M3 节点；不复制 M2 状态机。
- 新几何参数使用 Inspector 字段并提供合理默认值，包括探头入射点、13°槽、0mm/120mm 锚点、熔合线段、内部损伤点、射线长度及角度/距离/双点容差。
- M3 runtime 脚本各保持不超过 150 行；`M3FlowController` 和 `M3ProbeDrag` 当前已为 150 行，实施前必须删除旧“进度即距离”、反射束和单点判定，不能继续堆叠。
- 不由 Agent、Setup 或 runtime 修改/保存 `M3.unity`，不修改 M1/M2 Scene、M2 业务脚本、QA 网络链路、素材文件或 Build Settings。

2. 将 `Assets/交互动画素材/03 其他素材/多功能尺子.png` 绑定到 `Ruler/bg`，开启适合该素材的 preserveAspect，并处理现有 `RulerPlaceholderLabel`；当前审计中 `Ruler/bg.Image.m_Sprite` 为空。
