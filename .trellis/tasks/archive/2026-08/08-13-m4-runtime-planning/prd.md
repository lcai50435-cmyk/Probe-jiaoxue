# M4 运行时实现规划

## 目标

在 M4 静态 Scene 通过三视口审核并冻结后，基于其真实层级、节点引用、最终素材和视觉坐标，编写可直接执行的 M4 runtime 产品要求、技术设计与实现清单。

## 前置依赖

- `08-13-m4-static-scene-ugui` 已完成并记录冻结 Scene SHA-256。
- 老板已确认向上 10°的视觉方向、多功能尺最终形态以及轨腰最上端的探头构图。
- 老板 2026-08-13 确认钢轨红色区域为唯一损伤目标。探头入射点到红色损伤中心的距离为 40mm；`WeldLine` 仅作视觉参照，不参与检出或测距成功判定。
- 运行时规划必须重新静态核查冻结后的 `Assets/Settings/Scenes/M4.unity`，不得沿用规划阶段假设的节点路径。

## 规划范围

1. Intro 2 秒耦合剂展示、Positioning/Scanning/Detected/Measuring/Completed 流程；检出后先锁定并等待玩家进入复测，不自动跳过反馈。
2. 定位依次完成：探头以 0°放到轨腰最上端、Slider 调至向上 10°、同一多功能尺的 10°槽对准探头且尺身基准线平行钢轨底边；缺少任一条件不得扫描。
3. 建立单一几何合同：多功能尺 `0→40mm` 二维锚点跨度是毫米比例；探头入射点、红色损伤中心、绿色检测束和尺子双点复测共用 `RailViewport` 本地像素坐标。
4. 玩家从 80mm 起点移动至 40mm；仅在保持 10°、几何距离进入 40mm 容差且绿色检测束命中红色损伤区时报警一次、锁定探头和峰值。80→30mm 仅为波形参考域，不允许检出后继续拖至 30mm。
5. 同一把尺实现 Home/AngleGuide/DistanceMeasure 双工作模式；最终由玩家把 `0mm` 对准探头入射点、`40mm` 对准红色损伤中心，两点同时进入容差才完成，禁止自动测距或单点吸附通过。
6. 普通/透视只控制可见层，不改变几何、检出和流程状态；绿色检测束校角后持续更新，入射束参与命中，反射束如保留只作视觉。
7. 30 秒帮助完整演示放置、Slider 和尺子校角；60 秒帮助沿手动同一几何路径移动到 40mm，并经过相同命中判定；Reset/QA/Modal 恢复和暂停所有相关状态。
8. M1 QA/数字人及 `M2WaveformGraphic` 复用；仅复用 M2/M3 的通用机制，不复制其状态机、归一化进度距离、阈值越线检出或尺子单点吸附合同。
9. Inspector `UnityEvent` M5 出口，未配置时保持完成态；Play Mode 烟测、三视口运行时验收和冻结 Scene 不变合同。

## 交付物

- 收敛后的 `prd.md`。
- 基于真实节点和复用边界的 `design.md`。
- 含验证命令、回滚点和检查门槛的 `implement.md`。
- 供实现/检查子代理使用的 `implement.jsonl`、`check.jsonl`。

## 验收标准

- [ ] 所有路径与冻结 M4 Scene 真实层级逐层一致。
- [ ] 参数、方向、扫描轨迹、几何比例和文案均为 M4 专属合同，不沿用 M3 默认值或归一化进度伪造距离。
- [ ] 红色损伤中心是检测束、40mm 距离和尺子 40mm 锚点的唯一目标；`WeldLine` 不参与成功判定。
- [ ] Slider 单条件、尺子单点、光束未命中和检出后继续拖动均有负例；尺子双模式、手动/帮助同位命中、一次蜂鸣和 Reset 复跑有正例。
- [ ] 明确哪些组件直接复用、哪些需参数化、哪些必须新建，并符合低代码优先。
- [ ] 规划覆盖独立验收，不把未实现的 M5 或串联作为前提。
- [ ] 本子任务不修改业务代码或 Scene。
