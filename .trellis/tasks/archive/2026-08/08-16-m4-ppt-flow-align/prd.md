# M4 轨腰探测：复制 M3 基线 + 波形/几何参数对齐 PPT

## 背景与口径（2026-08-17 老板定稿，替代旧 M2 复用口径）

老板明确指示：**M4 = 复制 M3 模块全套**（Scene + runtime 脚本 + Editor 工具），M4 相对 M3 **只有波形图变化和探头、尺子、射线的位置/角度变化**，其余（流程骨架、伤损变色、无耦合剂、检出即测距、防卡死、QA 暂停）全部沿用 M3 已验证行为。

已确认的产品口径：

- 流程：`Positioning(0° 放置 + 定位尺水平 + 探头向上偏 10°) → Scanning(55→40mm 检出锁定) → Measuring(尺子 0/40mm 双点) → Completed`，无耦合剂开场（与 M3 一致删除）。
- 扫描起点 = PPT 中轨腰左侧几何位置（不超出轨道）；伤损波形起点 = 波形窗口 55mm 处。
- 探头起始：钢轨左侧、接近轨腰最上端、无偏角；借助定位尺（水平放置）将探头**向上偏转 10°**。
- 目标距离 40mm（红色损伤中心，PPT 写"焊缝熔合线"以老板确认的红色损伤为准）。
- 波形复用 `M2WaveformFx`：`appearMm=55`、`peakMm=45`、`stopMm=40`；初态 55mm 短波，45mm 最高，40mm 停止锁定。
- 射线：只能打到轨腰最顶部，不能穿透到轨头；正常绿色，检出后橙色。
- 伤损反馈：检出后红色损伤（红椭圆）变橙色（与 M3 现实现一致）。
- 尺子复用 `尺子正面.png`：定位 10° 校角 + 测量 `0→40mm` 双点（PixelsPerMm 来自 0→40 标定）。
- 素材：钢轨 `Assets/railwayTracks_2/正视角透明.png`、探头 `probeFootage/probeFootage.png`、尺子 `Ruler/尺子正面.png`（与 M3 完全同款）。
- 完成出口："轨腰部位探测完成"，Inspector UnityEvent 接下一模块；未配置显示"下一模块待接入"。

## 边界（硬性）

- **M3 只准看、不准改**：M3.unity、M3 脚本、M3 Editor 工具均不得修改（含伤损变色实现与素材来源，已核对与老板描述一致）。
- M2/M1 冻结 Scene 不得修改。
- M4 新建 `Assets/Settings/Scenes/M4.unity`，M4 脚本为 M3 脚本复制改名（`M3Xxx → M4Xxx`，namespace `M3 → M4`），不修改 M3 原文件。
- M4 为未冻结模块，Scene 可自由修改/重建；不改 M3 视觉权威。

## 验收标准

1. M4 Scene 存在且为 M3 Scene 复制基线（视觉 90%+ 一致，仅波形参数/探头/尺子/射线几何不同）。
2. M3.unity SHA-256 与本次实施前记录值完全一致（禁止任何 M3 改动）。
3. 波形参数 `appearMm=55/peakMm=45/stopMm=40`；初态 55mm 短波、45mm 最高、40mm 锁定。
4. 扫描距离 55→40mm；40mm 检出后探头锁定，不再继续。
5. 探头向上偏转 10° 校角成功；尺子水平放置（定位阶段），10° 槽校角。
6. 测量阶段 0mm 刻度对齐探头入射点、40mm 刻度对齐红色损伤中心。
7. 射线绿色→橙色检出反馈；伤损红椭圆变橙；Reset 恢复。
8. 无耦合剂开场，进入 M4 直接定位。
9. M4RuntimeSmoke 全 PASS；M4Shot 三视口非空。
10. 完成出口按 Inspector 配置显示"轨腰部位探测完成"/"下一模块待接入"。
