# 微信小游戏转换发布

## Goal

把现有 Unity 钢轨探伤教学项目（M1~M5）转成微信小游戏：先走**体验版**（方案 A）小范围验收，确认后再走**正式上线**（方案 B）。让安卓 + iPhone 的微信用户点开即玩，无需安装 App。

## Background

### 项目现状
- Unity 6000.3.21f1（WebGL 模块已装）、IL2CPP、URP 2D + Input System + TMP、UGUI 1920×1080 基线。
- 素材 ~180MB：数字人 8 个黑底 mp4（90MB）+ 8 个带透明通道 webm（9MB）；引导/教学演示 mp4 约 5 个（~40MB）。
- 视频链路核心：`M1IntroVideo` + `UI-LumaKey`（VideoPlayer→RenderTexture→shader 黑底抠像）。
- 本机已装引擎：2021.3.45f2、**2022.3.62f3**、6000.3.20f1、6000.3.21f1、6000.4.6f1。

### 微信平台硬约束
- 首包 ≤4MB（引擎 wasm 占大头），整包 ~20MB → 绝大部分资源必须远程 CDN。
- Unity `VideoPlayer` 在小游戏不可用；`WX.video` 是浮于画面上方的原生层，无法进 RenderTexture → LumaKey 链路失效。
- 真机强制校验 request 合法域名；`api.deepseek.com` 不在自己名下无法配置 → AI 问答直连不可行。
- 官方转换 SDK `minigame-tuanjie-transform-sdk` 已验证版本仅 Unity 2018~2022 与团结引擎；本项目 Unity 6000.3 **不在列表内**（见 Key Decisions D1 的应对）。
- 云开发免费环境（未上线阶段）：存储 2GB、CDN 流量 5GB/月；超量不自动扣费，仅当月受限。

### 发布路线（用户已拍板）
- 先 A（体验版）：免审核、免备案、零费用；体验成员几十人上限。
- 后 B（正式上线）：注册→备案→提审；上线 15 天后云资源转付费（19.9 元/月起）。
- 账号由用户本人注册（个人主体），将开发者微信加为项目成员协作。

## Requirements

- R1 转换基线：安装官方转换 SDK，完成 WebGL 构建 + 转换出小游戏工程并在开发者工具中运行 M1。
- R2 首包达标：Boot 场景 + 引擎代码首包 ≤4MB；其余资源全部远程化并可进度可视化加载。
- R3 数字人适配：序列帧数字人替换现有视频数字人，三态切换正常，视觉接近现状。
- R4 引导视频适配：M1 开场引导在小游戏内可播放（按 D3 路径）。
- R5 AI 问答可用：真机上问答经云函数中转正常工作，Key 不进前端包。
- R6 体验版交付：上传体验版并生成二维码，目标用户体验流畅（iPhone 不闪退）。
- R7 存量合同不破坏：Android APK 路线保持可构建；M2/M3 冻结 Scene 约定继续有效（转换改造不得重写冻结视觉）；改造代码以平台宏/独立文件隔离，不污染原生管线。

## Acceptance Criteria

- [ ] 开发者工具中 M1 可进入并操作，首屏出现自制 Loading 页且无白屏卡顿。
- [ ] 首包体积 ≤4MB（转换面板实测）。
- [ ] 真机（至少一台 Android + 一台 iPhone）完整跑通：Boot 加载 → 引导视频 → 探伤流程 → 数字人三态切换 → AI 问答一轮对话。
- [ ] iPhone 真机连续游玩 5 分钟无内存闪退。
- [ ] 体验版二维码分发给 ≥10 名用户体验。
- [ ] Unity Editor 内 Android 构建回归成功（APK 打包一次通过）。

## Out of Scope

- 正式上线事项（备案提交、提审材料、类目资质）——B 阶段另起任务。
- 原生 iOS 出包（已评估放弃）、WebGL 网页版独立发布。
- 游戏玩法/教学内容变更。
