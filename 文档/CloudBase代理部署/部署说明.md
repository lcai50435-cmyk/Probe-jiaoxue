## 1. 部署步骤

1. 登录 CloudBase 控制台（环境 `cloud1-d6gmycfs6b37edb43`，与静态托管同环境）。
2. 云函数 → 新建函数 `deepseek-proxy`，运行时 Node.js 16+，内存 128MB，超时 35s，上传 `index.js`。
3. 函数配置 → 环境变量：
   - `DEEPSEEK_API_KEY`：**轮换后的新 Key**（旧 Key 已进过客户端风险范围，必须作废重建）。
   - `DEEPSEEK_MODEL`：`deepseek-chat`（可选）。
   - `DEEPSEEK_SYSTEM_PROMPT`："铁小探"人设（可选，默认值同客户端旧人设）。
4. 云函数 → HTTP 访问服务 → 开启并绑定路径（如 `/deepseek-proxy`），得到形如
   `https://<env-id>.service.tcloudbase.com/deepseek-proxy` 的 URL（必须 https）。
5. 把该 URL 填入 Unity `Assets/Resources/AiProxyConfig.asset` → `proxyUrl`，重新导出微信。
6. 微信公众平台 → 开发管理 → 开发设置 → 服务器域名：把上述 CloudBase 域名加入 **request 合法域名**。

## 2. 安全要点

- 旧 DeepSeek Key 已随 `DeepSeekConfig.asset` 进入过 WebGL 构建产物，**必须在 DeepSeek 平台作废并换新**；
  新 Key 只存在于云函数环境变量。
- 云函数日志只输出错误类别（`upstream_5xx` 等），不输出消息内容与凭据。
- 内置简单限流（同 IP 60s/10 次）；体验版规模足够，公开发布前建议换成集中式计数。
