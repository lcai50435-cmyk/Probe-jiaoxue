# 微信小游戏接入准备

## 产物边界

Android Debug APK 仅用于 USB 真机验收，不能上传或转换为微信小游戏。微信小游戏必须使用官方 Unity 微信小游戏转换 SDK 生成对应工程，再通过微信开发者工具预览、调试和上传。

## 后续需要提供或安装

1. 与当前 Unity 版本兼容的官方 Unity 微信小游戏转换 SDK。
2. 微信小游戏 AppID 及相应账号权限。
3. 微信开发者工具和有效登录账号。
4. 微信小游戏性能、分包、隐私和网络请求所需的后台配置。

## 当前工程的重点兼容性风险

- 数字人依赖 `VideoPlayer`、RenderTexture 与 LumaKey；微信小游戏运行环境需优先做真机视频解码和 RenderTexture 验证。
- AI 问答使用网络请求。正式接入时不得把 DeepSeek Key 放入小游戏客户端；应改为自有服务端代理。
- 当前 UGUI 横屏布局可作为转换起点，但微信容器的安全区、内存、包体和触控行为需重新真机验收。
- 不能以普通 Unity WebGL 构建或 Android APK 代替官方微信小游戏转换产物。

## 推荐接入顺序

1. 先完成 Android 真机流程和视频/触控验收。
2. 安装官方 SDK，创建独立转换分支或副本，避免污染 Android 发布配置。
3. 完成最小 M1 场景转换和微信开发者工具真机预览。
4. 验证视频、问答服务代理和安全区后，再扩展至 M2-M5。
5. 按微信小游戏后台要求完成分包、性能、隐私和提审资料。
